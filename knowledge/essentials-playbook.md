# 精华执行总纲（去冗余版）

## 一条主线
小说输入 -> 分析 -> 分集 -> 写集 -> 双审 -> 分镜桥接 -> 视频化。

## 两条分镜流
1. **标准分镜流**：Beat breakdown -> Beat Board -> Sequence Board -> Motion Prompt
2. **Seedance 流**：导演分析 -> 服化道设计 -> Seedance 提示词

## 五条硬规则
1. 不能贴书改：心理描写转台词/动作/镜头。
2. 节奏硬约束：3秒钩子，15秒小冲突，60秒反转，集尾悬念。
3. 一致性硬约束：称呼规范表、人设锚点、道具锚点、关系锚点。
4. 审核硬约束：每阶段业务审+合规审，FAIL 必回改。
5. 可验证硬约束：每轮必须 grep 乱码和称呼错误。

## 质量判定最小集
1. 本集是否有明确冲突升级？
2. 台词是否口语化且信息密度足够？
3. 情绪是否有起伏而非单调推进？
4. 结尾是否强钩子驱动下一集？
5. 跨集设定是否与角色档案一致？
