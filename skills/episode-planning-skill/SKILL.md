## 卡纲必备要素

每集卡纲必须包含以下要素：

### 1. 完整事件流程图
用箭头标注当集的完整事件流程，格式如：
```
完整事件：宣布 → 搜身 → 揭露真相 → 签字 → 纪念册 → 离开
```

### 2. 内容概括
用一两句话概括当集内容，例如：
- "萧家宣布驱逐，搜身揭露真相，主角签字离开"
- "主角在拍卖会上展示实力，震惊全场"

### 3. 事件完整性原则
- **一个完整事件应该在一集内完成**
- 不要把连续动作（如搜身、签字、离开）拆成多集
- 每集应该是一个独立的故事单元
- 相邻集之间应该是不同的场景或事件

**反例**：
- 第1集：搜身 + 签字 + 离开
- 第2集：搜身 + 签字 + 离开（重复）

**正例**：
- 第1集：被赶出萧家（完整事件：宣布 → 搜身 → 签字 → 离开）
- 第2集：拍卖会展示实力（完整事件：入场 → 竞拍 → 展示 → 震惊）

## 成功标准
1. 每集冲突/反转/钩子齐全
2. 情绪曲线满足约束
3. 付费卡点明确
4. **每集卡纲包含完整事件流程图**
5. **每集卡纲包含内容概括**
6. **相邻集之间无重复内容**
