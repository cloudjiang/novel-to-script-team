# Show Don't Tell 技能

## 必读
1. `../../references/13-show-dont-tell-methodology.md`
2. `../../references/03-script-writing-standard.md`
3. `../../references/10a-action-dialogue-scenes.md`

## 核心任务

将抽象情绪翻译为可拍摄的动作和画面，让观众通过看到的画面感受情绪，而不是被告知情绪。

---

## 执行流程

### 步骤1：扫描识别

扫描剧本，识别所有情绪形容词：

#### 1.1 情绪形容词黑名单

参考 `references/13-show-dont-tell-methodology.md` 第一章，识别以下类型：

**基础情绪类**：
- 伤心、难过、悲伤、痛苦、心碎
- 开心、高兴、快乐、兴奋、激动
- 愤怒、生气、恼火、暴怒、愤恨
- 害怕、恐惧、惊恐、紧张、不安
- 惊讶、震惊、意外、诧异、惊愕

**复杂情绪类**：
- 失望、绝望、无助、无奈、迷茫
- 尴尬、羞愧、内疚、后悔、自责
- 嫉妒、羡慕、不甘、憋屈、委屈
- 冷漠、麻木、疲惫、厌倦、无聊
- 温柔、温暖、感动、心疼、怜惜

**状态描述类**：
- 紧张、焦虑、慌乱、不知所措
- 犹豫、纠结、矛盾、挣扎、动摇
- 坚定、果断、决绝、冷静、淡定
- 疲惫、虚弱、无力、崩溃、绝望

#### 1.2 允许的网文感情绪词

以下词可以保留（但必须配合具体动作）：
- 冷笑、嗤笑、冷哼、轻笑、讥笑
- 眼神一冷、目光一沉、脸色一变
- 嘴角上扬、眉头一挑、眼神闪烁

#### 1.3 识别输出格式

```markdown
## 情绪形容词清单

| 位置 | 原文 | 情绪类型 | 严重程度 |
|------|------|---------|---------|
| 第2场 第3行 | "她很伤心" | 伤心 | 高（直接使用黑名单词） |
| 第3场 第5行 | "他愤怒地说" | 愤怒 | 中（副词形式） |
| 第4场 第8行 | "她失望极了" | 失望 | 高（直接使用黑名单词） |

**统计**：
- 情绪形容词总数：12个
- 剧本总字数：3500字
- 情绪形容词密度：3.4个/1000字（超标，目标 ≤ 2个/1000字）
```

---

### 步骤2：情绪分类

对每个识别出的情绪形容词，判断情绪类型：

| 情绪类型 | 子类型 | 翻译策略 |
|---------|--------|---------|
| 伤心/难过 | 轻度、中度、重度 | 使用克制动作（咬唇、低头、转身） |
| 愤怒/生气 | 压抑、爆发、冷怒 | 使用爆发动作（站起、摔、握拳） |
| 害怕/恐惧 | 紧张、恐惧、惊恐 | 使用防御动作（后退、颤抖、攥衣角） |
| 惊讶/震惊 | 意外、震惊、难以置信 | 使用中断动作（停住、愣住、掉落） |
| 失望/绝望 | 失望、心灰意冷、绝望 | 使用放弃动作（垂眼、垂手、放下） |
| 尴尬/羞愧 | 尴尬、羞愧、内疚 | 使用回避动作（躲闪、低头、转身） |
| 犹豫/纠结 | 犹豫、纠结、举棋不定 | 使用重复动作（反复、来回、悬停） |
| 冷漠/麻木 | 冷漠、麻木、无动于衷 | 使用机械动作（机械点头、无反应） |

---

### 步骤3：动作化翻译

参考 `references/13-show-dont-tell-methodology.md` 第二章的翻译表，为每个情绪提供3个改写方案：

#### 3.1 翻译输出格式

```markdown
## 改写建议

### 位置：第2场 第3行

**原文**：
```
※ 她很伤心，眼泪止不住地流下来。
```

**问题**：
1. 直接使用情绪形容词"伤心"
2. "眼泪止不住"太直白，缺乏层次
3. 缺乏具体动作和环境细节

**改写方案1（推荐）**：
```
※ 她低头盯着手机屏幕，拇指悬在发送键上方，颤抖着，最终还是删掉了整段文字。
△ 她咬紧下唇，眼眶泛红，但强忍着没让泪水落下。
```
- 景别：特写（手机屏幕）+ 中景（咬唇、眼眶）
- 优点：克制、有层次、有具体动作
- 情绪传达：通过"删掉文字"和"强忍"传达伤心

**改写方案2**：
```
※ 她靠在墙上，缓缓滑坐到地上，双手抱住膝盖，把脸埋进臂弯里。
△ 她的肩膀微微颤抖，但没有发出任何声音。
```
- 景别：全景（滑坐）+ 中景（肩膀颤抖）
- 优点：视觉冲击力强，孤独感明显
- 情绪传达：通过"滑坐"和"埋脸"传达伤心

**改写方案3**：
```
※ 她站在窗前，看着外面的雨，手指在玻璃上画了一个圈，又慢慢抹掉。
△ 她深吸一口气，闭上眼睛，眼角有泪痕。
```
- 景别：侧面中景（窗前）+ 特写（泪痕）
- 优点：有环境细节（雨），有象征动作（画圈抹掉）
- 情绪传达：通过"雨"和"抹掉"传达伤心

**推荐理由**：
方案1最符合短剧节奏，动作具体、克制、有层次，且符合"可控剧本三问"（人物≤2、动作简单、情绪段落清晰）。
```

### 步骤4：景别标注

为每个改写方案标注推荐景别：

| 情绪类型 | 推荐景别 | 原因 |
|---------|---------|------|
| 细腻情绪（伤心、失望） | 特写/大特写 | 捕捉微表情和细节 |
| 爆发情绪（愤怒、惊讶） | 中景/全景 | 展现肢体动作和空间关系 |
| 压抑情绪（冷漠、麻木） | 中景 | 保持距离感，强调隔阂 |
| 复杂情绪（犹豫、纠结） | 特写+全景交替 | 内心挣扎与外部环境对比 |

参考 `references/08-camera-and-cinematography.md` 的景别定义。

---

### 步骤5：视觉化评分

#### 5.1 评分维度

| 维度 | 权重 | 评分标准 |
|-----|------|---------|
| 情绪形容词密度 | 30% | ≤ 2个/1000字 = 满分，每超1个扣5分 |
| 动作描写占比 | 25% | ≥ 30% = 满分，每少5%扣5分 |
| 对话占比 | 20% | ≥ 50% = 满分，每少5%扣5分 |
| 具体动作数 | 15% | 每场戏 ≥ 3个 = 满分，每少1个扣3分 |
| 环境细节数 | 10% | 每场戏 ≥ 1个 = 满分，没有扣10分 |

#### 5.2 评分输出格式

```markdown
## 视觉化评分

### 量化指标

| 指标 | 实际值 | 目标值 | 得分 | 权重 | 加权得分 |
|-----|--------|--------|------|------|---------|
| 情绪形容词密度 | 3.4个/1000字 | ≤ 2个/1000字 | 23/30 | 30% | 6.9 |
| 动作描写占比 | 25% | ≥ 30% | 20/25 | 25% | 5.0 |
| 对话占比 | 55% | ≥ 50% | 20/20 | 20% | 4.0 |
| 具体动作数 | 平均2.5个/场 | ≥ 3个/场 | 13/15 | 15% | 1.95 |
| 环境细节数 | 平均0.8个/场 | ≥ 1个/场 | 8/10 | 10% | 0.8 |

**总分**：18.65 / 25 = **74.6分**

### 评级

- 90-100分：优秀（PASS，无需修改）
- 70-89分：良好（PASS，建议优化）
- 50-69分：及格（FAIL，需要修改）
- < 50分：不及格（FAIL，需要大幅修改）

**本剧本评级**：良好（PASS，建议优化）

### 主要问题

1. **情绪形容词密度超标**（3.4 > 2.0）
   - 第2场、第4场、第7场使用了直接情绪形容词
   - 建议全部改写为动作化表达

2. **动作描写占比不足**（25% < 30%）
   - 部分场景缺乏具体动作描写
   - 建议增加肢体动作和微表情描写

3. **环境细节不足**（平均0.8个/场 < 1个/场）
   - 第3场、第5场缺乏环境细节
   - 建议加入环境细节增强情绪感染力

### 优点

1. **对话占比达标**（55% > 50%）
   - 对话自然、口语化、情绪化
   - 符合短剧节奏

2. **整体结构清晰**
   - 情绪段落明确
   - 冲突密度合理
```

## 使用场景

### 场景1：阶段3（写集）- 自查

`script-writer` 在写作完成后，使用本 skill 自查：

1. 扫描识别情绪形容词
2. 自我评分
3. 如果 < 70分，自行改写后再提交

### 场景2：阶段4（复核）- 审核

`visual-storyteller` 在审核时，使用本 skill：

1. 生成完整的视觉叙事报告
2. 提供详细的改写建议
3. 判定 PASS/FAIL

### 场景3：阶段4（复核）- 辅助审核

`review-director` 在综合审核时，参考本 skill 的评分：

1. 查看视觉化评分
2. 结合业务审核和合规审核
3. 做出最终判定

- **script-writing-skill**：定义如何写作剧本
- **本 skill**：定义如何将情绪翻译为动作

**协同使用**：
1. 先用 script-writing-skill 生成剧本
2. 再用本 skill 检查视觉化程度

- **style-analysis-skill**：分析语言风格（句长、对话比、网文感）

**协同使用**：

3. 本 skill 关注视觉化程度

- **本 skill**：确保剧本的视觉化程度

**协同使用**：
1. 本 skill 在剧本阶段确保情绪可视化
2. storyboard-review-skill 在分镜阶段确保视觉呈现
3. 两者确保从剧本到分镜的视觉连贯性

## 常见问题

### Q1：网文感情绪词（冷笑、嗤笑）算不算情绪形容词？

**A**：不算。这些词已经成为类型化标记，可以保留。但必须配合具体动作使用：

- ❌ 他冷笑一声
- ✅ 他嘴角上扬，眼神冰冷，冷笑一声："你以为我会信？"

### Q2：如果情绪形容词密度略微超标（2.5个/1000字），是否必须改写？

**A**：不一定。如果：
1. 总分 ≥ 70分
2. 超标部分是网文感情绪词
3. 其他维度表现优秀

可以标记为 PASS（建议优化），不强制改写。

### Q3：如何判断一个动作是否"情绪化"？

**A**：检查三点：
1. **具体性**：动作是否具体明确？
2. **可拍性**：动作是否可以被摄影机捕捉？
3. **情绪传达**：观众能否通过动作感受到情绪？

如果三点都满足，则是"情绪化"动作。

### Q4：是否所有情绪都必须翻译为动作？

**A**：是的。剧本中不应出现任何直接的情绪形容词（除了网文感情绪词）。所有情绪都必须通过动作、画面、对话来传达。
