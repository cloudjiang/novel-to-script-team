## 技能说明

分镜教练技能，用于：
1. 审核用户创作的分镜作品
2. 提供7周分镜练习计划的每日任务
3. 给出具体、可执行的改进建议

## 执行模式

### 模式1：分镜审核

**输入**：用户提交的分镜作品（文本或图片）

**审核维度**：

#### 1. 格式规范检查
- [ ] 是否包含：镜号｜景别｜运镜｜时长｜画面｜台词/音效
- [ ] 镜号是否连续编号
- [ ] 时长是否标注（秒）
- [ ] 画面内容是否可视化（无心理描写）

#### 2. 景别选择检查
- [ ] 环境/氛围 → 远景/全景+固定 ✓
- [ ] 人物对话 → 中景/近景+正反打 ✓
- [ ] 情绪/细节 → 特写+微推 ✓
- [ ] 追逐/移动 → 跟镜头/移镜头 ✓
- [ ] 景别是否符合叙事需求

#### 3. 运镜合理性检查
- [ ] 镜头运动是否有动机
- [ ] 推镜头：聚焦、紧张、亲密 ✓
- [ ] 拉镜头：揭示、疏离、结束感 ✓
- [ ] 摇镜头：环顾、跟随水平运动 ✓
- [ ] 跟镜头：跟随人物移动 ✓
- [ ] 固定镜头：稳定、客观 ✓

#### 4. 镜头衔接检查
- [ ] 动作接动作（伸手→接东西）
- [ ] 景别递进（全景→近景）
- [ ] 视线匹配（看左→切左边画面）
- [ ] 出入画（人走出→下镜走进）
- [ ] 因果关系（摔倒→扶起来）
- [ ] 正反打（A说话→B反应）
- [ ] 是否有跳戏、断层

#### 5. 时长控制检查
- [ ] 对话1句 ≈ 2秒
- [ ] 空镜/氛围 ≈ 3-5秒
- [ ] 动作镜头 ≈ 1-3秒
- [ ] 总时长是否合理

#### 6. 叙事逻辑检查
- [ ] 是否有起承转合
- [ ] 信息传递是否清晰
- [ ] 是否有冗余镜头
- [ ] 是否符合"减法原则"（镜头越少越好）

#### 7. 可拍性检查
- [ ] 画面内容是否可视化
- [ ] 是否避免心理描写
- [ ] 是否避免抽象概念
- [ ] 是否符合物理规律

**输出格式**：

```markdown
## 分镜审核报告

### 总体评价
- 评分：X/10
- 等级：优秀/良好/及格/需改进
- 总结：[一句话总结]

### 亮点
1. [具体亮点1]
2. [具体亮点2]

### 问题清单
| 镜号 | 问题类型 | 具体问题 | 修改建议 |
|------|---------|---------|---------|
| 3 | 景别选择 | 情绪高潮用了全景，无法突出表情 | 改为特写，聚焦人物面部 |
| 5-6 | 镜头衔接 | 景别跳跃过大（全景→特写） | 中间插入中景过渡 |

### 改进示例
**原版**：
镜3｜全景｜固定｜3s｜男主很伤心｜无

**修改后**：
镜3｜特写｜微推｜2s｜男主眼眶泛红，手指攥紧衣角｜（叹气）

### 下一步建议
1. [具体建议1]
2. [具体建议2]
```

### 模式2：练习指导

**7周分镜练习计划**

#### 第1周：认识镜头——只练「景别+构图」

**目标**：看到画面立刻说出景别

**每日任务**（每天8格分镜，只画静态）：
- Day1：全景+中景（人物全身/半身）
- Day2：近景+特写（胸口以上/局部）
- Day3：俯拍+仰拍（各4格）
- Day4：居中构图、对称构图
- Day5：三分法、留白构图
- Day6：复习：随机抽8个景别+构图组合
- Day7：自由临摹1张影视截图，拆成8格景别

**检查清单**：
- [ ] 每格标注景别名称
- [ ] 每格标注构图方式
- [ ] 画面框清晰
- [ ] 不需要画精细，火柴人+方框即可

---

#### 第2周：运镜基础——只练「镜头怎么动」

**目标**：会写推/拉/摇/移/跟/固定

**每日任务**（每天6格运镜分镜）：
- Day1：固定镜头（不动）6格
- Day2：推镜头（靠近）6格
- Day3：拉镜头（远离）6格
- Day4：左右摇镜头6格
- Day5：上下摇+平移6格
- Day6：跟拍（人物走→镜头跟着）6格
- Day7：混合：固定/推/摇/跟各1-2格

**检查清单**：
- [ ] 每格标注运镜方式
- [ ] 配简单动作
- [ ] 用箭头标注镜头运动方向

---

#### 第3周：单镜头叙事——1个镜头讲清一件事

**目标**：一个镜头就有「起→过程→结果」

**每日任务**（每天3-5格，每格一个完整小事件）：

**示例主题**（每天换一个）：
- 开门→进门→关门
- 拿水杯→喝水→放下
- 坐下→看手机→抬头
- 走路→停下→转身
- 开灯→照亮→关灯

**检查清单**：
- [ ] 标注时长（2-5秒）
- [ ] 标注动作
- [ ] 有起承转合

---

#### 第4周：2镜衔接——入门剪辑逻辑（最关键）

**目标**：学会「镜头衔接不跳戏」

**每日任务**（每天6组双镜头，每组2格）：

**练习常见衔接**：
1. 动作接动作（伸手→接东西）
2. 景别递进（全景→近景）
3. 视线匹配（看左→切左边画面）
4. 出入画（人走出→下镜走进）
5. 因果关系（摔倒→扶起来）
6. 正反打（A说话→B反应）

**检查清单**：
- [ ] 两个镜头逻辑连贯
- [ ] 无跳戏感
- [ ] 符合观察习惯

---

#### 第5周：3镜小片段——开始有「节奏」

**目标**：建立「开场→发展→收尾」

**每日任务**（每天1个3镜小片段，10-15秒）：

**固定结构**：
1. 镜1：交代环境/人物（全景/中景）
2. 镜2：核心动作（近景/特写）
3. 镜3：结果/反应/收尾

**主题任选**：
- 丢垃圾、递东西、敲门、拍照、下雨躲雨、吃饭等

**检查清单**：
- [ ] 3个镜头有完整叙事
- [ ] 景别递进合理
- [ ] 总时长10-15秒

---

#### 第6周：10镜短剧（30秒完整片）

**目标**：第一次做「完整分镜脚本」

**每周任务**（每周2条，每条10镜以内）：

**固定模板**（直接套）：
1. 环境引入（2s）
2. 人物出现（2s）
3. 动机动作（3s）
4. 冲突/意外（3s）
5. 反应特写（2s）
6. 解决/反转（4s）
7. 收尾定格（2s）

**检查清单**：
- [ ] 严格写：镜号｜景别｜运镜｜时长｜画面｜台词/音效
- [ ] 总时长约30秒
- [ ] 有完整故事

---

#### 第7周：1分钟完整分镜（15-20镜）+复盘

**目标**：能独立接简单短剧/短视频分镜

**每日任务**：
- Day1-3：按上面结构扩到15镜，1分钟
- Day4-5：模仿你喜欢的短剧/抖音片段，拆分成镜
- Day6：自己原创1分钟小故事分镜
- Day7：复盘所有作品，挑3张最好的做成作品集

**检查清单**：
- [ ] 15-20个镜头
- [ ] 总时长约1分钟
- [ ] 完整故事+情绪曲线
- [ ] 格式规范

---

## 每日必做3个小规则

1. **每格必须写时长+景别+运镜**，不写不算完成
2. **不追求画得好看**，逻辑通顺 > 画工
3. **每周回看一次**，删掉最差的，保留进步痕迹

## 额外加分训练

- 每天看1条短视频，口头拆镜：几镜？什么景别？怎么转场？
- 每周临摹1个影视经典片段分镜（10镜内）

## 常见问题速查

### Q1：景别怎么选？
- 拍环境、氛围 → 远景/全景+固定
- 拍人物对话 → 中景/近景+正反打
- 拍情绪、细节 → 特写+微推
- 拍追逐、移动 → 跟镜头/移镜头

### Q2：时长怎么估算？
- 对话1句 ≈ 2秒
- 空镜/氛围 ≈ 3-5秒
- 动作镜头 ≈ 1-3秒

### Q3：镜头怎么衔接？
- 动作接动作（最安全）
- 景别递进（全景→中景→近景→特写）
- 视线匹配（看哪切哪）
- 因果关系（原因→结果）

### Q4：什么是"减法原则"？
- 能用1个镜头讲清，绝不拆成3个
- 镜头越少越好
- 每个镜头都要有明确目的

## 成功标准

### 审核模式
1. 7个维度全部检查
2. 给出具体问题位置和修改建议
3. 提供修改示例
4. 鼓励用户持续改进

### 练习指导模式
1. 根据用户当前周次提供对应任务
2. 提供检查清单
3. 给出示例参考
4. 追踪学习进度
