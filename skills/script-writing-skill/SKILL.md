# 写作技能

## 必读
1. `../../references/00-first-principles.md`
2. `../../references/03-script-writing-standard.md`

## 执行流程

### 1. 检索相关爆款剧本（生成前）
在生成前，调用 `hit-script-retrieval-skill` 检索Top 5相关集：
- 输入当前剧本特征（类型、情绪、结构、场景类型等）
- 获取Top 5最相关的集ID列表
- 加载这5个集的内容（约25KB）

### 2. 参考爆款剧本生成
参考检索到的5个集的特征：
- **语言风格**：句长、对话比、视觉标记频率
- **节奏模式**：场景数、冲突密度、情绪强度
- **网文感**：短句比例、网文感关键词（冷笑、嗤笑、冷哼等）
- **对话设计**：高对话比（70%以上）、短句、情绪化

## 生成前检查清单（可控剧本三问）

在生成剧本前，必须回答以下三个问题：

### 1. 这场戏能稳定生成吗？

**检查项：**
- [ ] 人物数量 ≤ 2（超过2人容易崩）
- [ ] 动作复杂度低（无肢体接触、无快速走位）
- [ ] 场景切换 ≤ 3次
- [ ] 情绪段落明确（建立→拉扯→爆点→反转/悬念）

**不可生成的动作：**
- 复杂肢体接触（拥抱、打斗、舞蹈、推搡）
- 快速走位（边说话边走动、追逐对话）
- 多人群戏（超过2人同框）

**可生成的动作：**
- 对视、沉默、微表情变化
- 欲言又止、情绪压抑
- 简单手势、缓慢移动

### 2. 情绪段落清晰吗？

**检查项：**
- [ ] 情绪建立（0-3秒）：场景和人物状态
- [ ] 情绪拉扯（3-8秒）：冲突展开
- [ ] 情绪爆点（8-12秒）：冲突高潮
- [ ] 情绪反转或悬念（12-15秒）：反转或钩子

**每段必须：**
- 有明确的情绪指向
- 可独立测试生成
- 避免模糊过渡

### 3. 有可传播的爆点台词吗？

**检查项：**
- [ ] 至少1句可截图传播的金句
- [ ] 台词口语化、短句、情绪化
- [ ] 符合网文感（冷笑、嗤笑、冷哼等）

**正确示例：**
- "你走。"（短句，情绪明确）
- "够了！"（情绪爆发，简洁有力）
- "这一世，我只为自己活。"（金句，可传播）

**错误示例：**
- "我已经不想再看到你那虚伪的面孔了。"（太文学）
- "此刻的我，内心充满了失望与愤怒。"（书面腔）

**如果三点不满足，重新设计结构。**

## 成功标准
1. 2-3 场景
2. 冲突+反转+悬念
3. 称呼与人设一致
4. 语言风格接近爆款剧本（句长12字符左右、对话比70%以上）
5. 节奏紧凑（场景数8左右、冲突密度0.03以上）
