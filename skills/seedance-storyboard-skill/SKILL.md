## 技能说明

将导演的讲戏内容转化为 Seedance 2.0 格式的动态视频提示词。每个剧情点 = 一段完整叙事 = 一条提示词 = 一次 Seedance 2.0 生成任务。段落内可包含多组镜头（如蒙太奇、连续切换）。提示词中使用 @引用语法关联人物和场景素材，输出可直接复制到 Seedance 2.0 平台生成视频。

## 输入
1. 导演讲戏本（`outputs/<集数>/01-director-analysis.md`）
2. 人物提示词（`outputs/{剧本名}/assets/character-prompts.md`）
3. 场景道具提示词（`outputs/{剧本名}/assets/scene-prompts.md`）

## 输出
1. `outputs/<集数>/02-seedance-prompts.md` — Seedance 2.0 提示词脚本（含素材对应表）

## 执行流程

### 第一步：读取上游产物
- 读取导演讲戏本（01-director-analysis.md）
- 读取人物提示词（assets/character-prompts.md）
- 读取场景道具提示词（assets/scene-prompts.md）

### 第二步：建立素材对应表
- 根据人物和场景提示词文件，为本集涉及的素材分配 @引用编号
- 只有在 character-prompts.md 和 scene-prompts.md 中有提示词的人物/场景才分配 @引用
- 不在素材文件中的人物（群演、一次性配角）不进对应表，在提示词中直接用文字描述
- 在文档头部建立对应表

**场景素材的编号规则（重要）**：
- scene-prompts.md 中的九宫格是"生成格式"——用于一次性生成场景参考图
- 生成后，用户会将九宫格中的每个格子单独提取出来，作为独立的场景参考图
- 因此在素材对应表中，每个场景必须独立编号为一个 @图片，不能将整张九宫格作为一个 @图片
- 编号顺序：先人物（按 character-prompts.md 顺序），再场景（按 scene-prompts.md 中的格子顺序）
- 示例：如果有 4 个人物 + 9 个场景，则 @图片1-4 为人物，@图片5-13 为场景

**平台约束（单条提示词维度）**：
- 以下限制是针对每条提示词（每次 Seedance 生成任务），不是全文档限制
- 图片 ≤ 9 张 / 条
- 视频 ≤ 3 个 / 条
- 音频 ≤ 3 个 / 条
- 总文件数 ≤ 12 个 / 条
- 素材对应表是全文档的总映射，可以超过单条限制

### 第二步半：为每条提示词选择生成模式

在编写提示词之前，根据导演讲戏本中每个剧情点的特征，预判生成模式。

**决策树**（按优先级从高到低）：
1. 需要精确 A→B 画面过渡（连续动作、无缝转场）？→ `首尾帧`（+生成首帧图和尾帧图）
2. 需要精确控制开场构图（硬切换景别/机位）？→ `I2V-首帧`（+生成首帧图）
3. 涉及多角色/场景一致性？→ `多参考`
   - 追加判断：≥ 8s 且多时段画面差异大？→ 需要分镜参考图
4. 纯氛围/概念镜头？→ `T2V`
5. 默认 → `多参考`

**模式叠加**：`I2V-首帧 + 多参考`、`首尾帧 + 多参考`（帧图占 @图片配额，总数 ≤ 9）

### 第三步：为每个剧情点编写 Seedance 2.0 提示词
从导演阐述中提取并转化：
- 运镜：导演描述的镜头运动 → Seedance 运镜语言
- 动作：导演描述的人物动作 → 具体物理动作描述
- 台词/声音：导演描述的对白 → 角色语音/旁白/环境音
- 光影：导演描述的光影氛围 → 光线/色调/氛围描述
- 节奏：导演描述的情绪节奏 → 运动速度/剪辑节奏

### 第三步半：输出帧图需求清单

汇总所有需要帧图的条目，输出到 `outputs/<集数>/03-frame-requests.md`。

### 帧图描述必备元素检查（参见 `references/20-frame-description-elements.md`）

每个帧图的「静态画面描述」必须包含以下必备元素：

**所有帧图必备（7 项）**：
- [ ] 景别（中景 / 全景 / 近景等）
- [ ] 机位角度（平视 / 俯拍 / 仰拍）
- [ ] 方位构图（中央 / 三分法 / 对称）
- [ ] 人物位置（在画面中的位置）
- [ ] 人物朝向（正面 / 侧面 / 背面 + 视线方向）
- [ ] 姿态动作（站 / 坐 / 具体动作）
- [ ] 光线类型（顶光 / 侧光 / 逆光等）

**近景 / 特写额外必备（+3 项）**：
- [ ] 表情眼神（面部表情 + 眼神状态）
- [ ] 光源方向（从哪个方向照来）
- [ ] 光影效果（高光和阴影位置）

**全景 / 远景额外必备（+4 项）**：
- [ ] 前景元素（前景物体或框架）
- [ ] 背景环境（背景空间描述）
- [ ] 景深效果（虚实关系）
- [ ] 人物与环境距离

**多人场景额外必备（+2 项）**：
- [ ] 人物关系（对峙 / 并排 / 距离）
- [ ] 人物与人物关系（距离 / 视线交汇）

**帧图描述要求**：
- 静态单帧画面（不含动作描述）
- 包含：构图、人物姿态、光影、色调
- 可引用现有角色/场景参考图

**输出格式**（兼容 generate_image.py 解析器）：
```markdown
# 帧图需求清单 — EP<N>

**视觉风格声明**：[与主提示词一致的风格声明]

---

## 帧图 F01：[对应剧情点] [帧图类型]

**参考图**：[引用的角色/场景]

[静态画面描述，构图、人物姿态、光影、色调]

---

## 帧图 F02：[对应剧情点] [帧图类型]

[静态画面描述]
```

**帧图编号规则**：F01, F02, F03... 按出现顺序编号

### 第四步：输出
按照标准格式输出到 `outputs/<集数>/02-seedance-prompts.md`

### 第四步半：帧图生成后更新 @引用

帧图由 `image-generator` 生成后，更新 `02-seedance-prompts.md` 中的引用：
- 帧图编号在现有素材编号之后顺延（如现有 @图片1-20，帧图从 @图片21 开始）
- 更新素材对应表，添加帧图条目
- 更新提示词中的帧图引用：
  - I2V-首帧：提示词开头加 `@图片N 作为首帧`
  - 首尾帧：提示词开头加 `@图片N 作为首帧，@图片M 作为尾帧`
  - 分镜参考图：在对应时段描述中加 `参考分镜图@图片N`

## Seedance 2.0 提示词写法核心规则

### 叙事描述式
- 用完整的导演式段落描述，不要关键词堆叠
- Seedance 2.0 擅长理解长段叙事性提示词
- 参考官方模板风格：连续段落，包含运镜、动作、光影、声音的融合描述

### 运镜描述
- 用具体方向和动作描述镜头运动
- ✓ "镜头从侧脸缓缓推向窗外夜色"
- ✗ "推镜头"（太简略）

**运镜词汇库**：
- **景别**：大远景、远景、全景、中景、近景、特写、大特写
- **运镜**：推镜头、拉镜头、摇镜头、移镜头、跟拍、环绕拍摄、航拍、手持跟拍、希区柯克变焦
- **角度**：平视、俯拍、仰拍、低角度、鸟瞰视角、鱼眼镜头、第一人称视角、主观视角
- **节奏**：慢动作、快切、延时摄影、一镜到底、升格拍摄、硬切、卡点
- **焦点**：浅景深、深景深、焦点转移、虚化背景、选择性对焦
- **特殊**：遮挡擦镜转场、无缝渐变转场、环绕摇镜快切特写、定格慢放

### 动作描述
- 用具体的物理动作，避免抽象概念
- ✓ "她揉了揉太阳穴，目光从屏幕移开，靠向椅背"
- ✗ "她感到疲惫"

### 时长控制
- 遵循导演建议的时长
- 底层规律：每个连续镜头内 1 拍 ≈ 2.5 秒屏幕时间，节拍太密动作会糊、跳、不自然
- 多镜头段落：节拍分布在多个镜头切换中，每个镜头各自遵守密度约束，总节拍可超单镜头上限
- 头尾安全区：每次 Seedance 生成前 0.5s 和后 0.5s 为安全区，不放关键内容

**时间戳分镜法**（10秒以上推荐使用）：
```
0-3秒：[画面描述 + 镜头语言]
4-8秒：[画面描述 + 镜头语言]
9-12秒：[画面描述 + 镜头语言]
13-15秒：[画面描述 + 镜头语言]
```

### 声音/台词
- 台词用引号标注
- 可指定语气/声音特征
- 可指定背景音乐风格
- 可指定环境音

**音频设计详细指导**：
- **背景音乐**：直接描述风格（恢宏大气/紧张悬疑/温暖治愈）或引用参考（背景BGM参考 @音频1）
- **音效设计**：环境音效（走路声、人群声、汽车声、雨声、风声）、动作音效（脚步声、呼吸声、衣料摩擦声）、情绪音效（心跳声、钟表声、回声）
- **音画同步**：转场画面与音乐节奏卡点、脚步声/呼吸声必须与画面动作贴合、音乐高潮与画面高潮同步
- **旁白/对话**：角色对白用引号标注，可指定音色参考（旁白音色参考 @视频1），可指定语气（哽咽、怒吼、低语、坚定）

**超长视频音频策略**（2-3分钟以上）：
- **问题**：Seedance 2.0 单次生成上限15秒，多段拼接时BGM会断开不连贯
- **解决方案**：生成静音版本（仅保留环境音和对白），后期统一配乐
- **提示词写法**：
  ```
  音效：保留环境音（雨声、脚步声、车声）和对白，不添加背景音乐
  ```
- **后期流程**：
  1. 生成所有15秒片段（只有音效和对白，无BGM）
  2. 用剪辑软件拼接所有片段
  3. 统一添加完整的BGM轨道（2-3分钟连续音乐）
- **优点**：音乐完全连贯，可自由选择BGM，各段可并行生成

### @引用语法
- @图片1、@图片2... → 参考图片（人物/场景参考）
- @视频1、@视频2... → 参考视频
- @音频1、@音频2... → 参考音频
- 务必明确说明每个引用的作用，不要只写"参考@视频1"而不说参考什么
- 示例："以@图片1中的林薇为主角，场景参考@图片3的深夜办公室"

### 参考图已见原则
- Seedance 2.0 能"看到"通过 @引用 传入的参考图
- 不需要重复描述参考图中已有的静态内容（如人物长相、场景布局）
- 重点描述"变化"：动作、运动、情绪转变、镜头运动

## 场景类型与提示词策略

### 电商/广告
- 产品360度旋转展示、爆炸分解、3D渲染特效
- 第一人称沉浸式手作体验
- 模仿参考视频的广告创意，替换产品主体
- 配合广告词和品牌logo

### AI漫剧/仙侠
- 使用首尾帧控制变身/变装效果
- 时间戳分镜法控制每段画面
- 详细的特效描述（法阵、能量波、粒子效果）
- 台词用引号标注，指定语气

### 短剧/对白
- 画面+台词分开描述，台词标注角色和情绪
- 音效单独描述
- 精准时长控制
- 可指定旁白说"预知后事如何，请看下集"

### 科普教学
- 4K医学CGI风格
- 半透明人体结构可视化
- 科学过渡自然流畅
- 配合教育性旁白

### MV/音乐卡点
- 指定画幅比（2.35:1）和帧率（24fps）
- 分镜头描述每个镜头的场景、动作、音效
- 强调声音设计与节拍同步
- 多图卡点参考视频节奏

## 超长视频分段策略

当需要超过15秒的视频时，采用**分段生成+视频延长拼接**的方式：

**核心原理**：先生成第一段视频（≤15秒），然后用「视频延长」功能，将上一段生成的视频作为输入，接续生成下一段内容。每次延长的时长就是新增部分的时长。

**分段规则**：
1. 将总时长按叙事节奏切分为多个片段，每段≤15秒
2. 每段之间必须有**画面衔接点**：上一段的结尾状态 = 下一段的开始状态
3. 第一段正常生成，后续每段使用「将@视频1延长Xs」的格式
4. 每段都要标注清楚属于整体的第几段、承接内容是什么

**输出格式**：
```
## 超长视频提示词（总时长约Xs）

**主题**：[一句话概括]
**总段数**：[N段]
**建议比例**：[16:9 / 9:16 / 1:1]

---

### 第1段（0-15秒）—— 正常生成

**生成时长**：15秒

#### 提示词

[完整提示词，时间戳分镜]

#### 衔接点

本段结尾画面：[精确描述结尾画面状态，用于下一段衔接]

---

### 第2段（15-30秒）—— 视频延长

**操作**：将第1段生成的视频上传为@视频1
**生成时长**：15秒

#### 提示词

将@视频1延长15秒。[接续内容的时间戳分镜描述]

#### 衔接点

本段结尾画面：[精确描述结尾画面状态]
```

**分段时长建议**：
- 16-30秒：2段（首段15秒 + 延长段）
- 31-45秒：3段
- 46-60秒：4段
- >60秒：建议拆分为独立场景分别生成，再用剪辑软件拼接

**超长视频音频处理**（>60秒）：
- **推荐策略**：生成静音版本（仅保留环境音和对白），后期统一配乐
- **原因**：多段拼接时BGM会断开，静音版本可确保后期配乐完全连贯
- **提示词调整**：每段都使用 `音效：保留环境音（雨声、脚步声、车声）和对白，不添加背景音乐`
- **后期流程**：拼接所有片段 → 统一添加完整BGM轨道
- **替代方案**：如果使用"视频延长"功能，BGM可能自动延续，但效果不如后期配乐稳定

## 高级提示词技巧

### 技术参数指定法

在提示词开头明确画面技术规格：
```
[尺寸]竖屏/横屏 + [画幅比]2.35:1/16:9/9:16 + [帧率]24fps + [时长]Xs + [色调/风格总纲]
```

示例：
```
2.35:1，24fps，15秒，8镜头硬切
霓虹高饱和冷暖对比，现代舞台
浅景深突出动作，动作清晰，运动模糊真实
声音设计优先：舞步声、鞋底摩擦、呼吸、衣料声必须清晰并与节拍贴合
禁止文字logo水印
```

### 禁止项声明

在提示词结尾声明不需要的元素，帮助模型规避常见问题：
```
禁止：
- 任何文字、字幕、LOGO或水印
- 不允许出现XXX
- 画面全部片段都不要出现字幕
```

## 群演/一次性配角处理

导演讲戏本中可能提到不在 character-prompts.md 中的人物（群演、一次性配角）。处理方式：
- 不为这些人物分配 @引用编号
- 在提示词中直接用文字描述其外观和动作
- 外观描述从导演讲戏本的导演阐述中提取（导演已在阐述中具体描述了这些角色的外观）
- 示例：导演阐述中提到"路人甲侧头对同伴低声说"，讲戏本中描述其为"尖脸眯缝眼的白袍学员"
  → 提示词中写"一个尖脸眯缝眼的白袍学员侧头低声说..."，不使用 @引用

## 禁忌规则

- 不要使用否定句（AI 不理解否定，可能产生相反效果）
  - ✗ "不要移动镜头"
  - ✓ "镜头保持固定"
- 不要重复导演讲戏本和人物/场景提示词中已有的静态内容描述
  - 重点描述"变化"：动作、运动、情绪转变
- 不要在一条提示词中塞入叙事上不相关的场景
  - 一条提示词 = 一个完整的叙事段落（可含多组镜头，但叙事连续）
- 不要使用与导演讲戏本和人物/场景提示词矛盾的描述
- 不要为不在 character-prompts.md 中的人物使用 @引用

## 成功标准
1. 素材对应表完整，每个场景独立编号（不将九宫格作为一个 @图片）

6. 不重复参考图中已有的静态内容，重点描述变化
7. 遵守时长控制和节拍密度约束
8. 不使用否定句
9. 群演/一次性配角直接用文字描述，不使用 @引用
10. 每条提示词可直接复制到 Seedance 2.0 生成视频
11. 每条提示词标注了生成模式和选型理由
12. 帧图需求清单完整（I2V/首尾帧模式都有对应帧图）
