# 20. 帧图描述完整元素表 (Frame Description Element Checklist)

## 概述

本文档整合 `references/08-camera-and-cinematography.md`、`references/11b-image-motion-prompt.md`、`references/15-color-psychology.md`、`references/17-lighting-narrative.md`、`references/19-micro-drama-storyboard-system.md` 中的视觉元素，提供帧图描述的完整 26 项元素清单。

所有生成帧图描述的 Skill（`seedance-storyboard-skill`、`art-design-skill`、`director-skill`）必须参照本清单，确保描述信息完整、可直接用于文生图 API。

## 元素分类与定义

### A. 镜头六要素 (Camera Core — 6 elements)

| # | 元素 | 说明 | 可选值示例 |
|---|------|------|-----------|
| 1 | **景别** | 画面中主体占比 | 远景 / 全景 / 中景 / 近景 / 特写 / 大特写 / 极特写 |
| 2 | **镜头运动** | 摄影机运动方式（帧图固定标注"固定"） | 推 / 拉 / 摇 / 移 / 跟 / 升降 / 固定 |
| 3 | **方位构图** | 主体在画面中的位置安排 | 中央构图 / 三分法 / 对称 / 对角线 / 框架构图 |
| 4 | **机位角度** | 摄影机相对主体的垂直角度 | 平视 / 俯拍 / 仰拍 / 荷兰角（倾斜） |
| 5 | **光线类型** | 主光源的性质和方向 | 顶光 / 侧光 / 逆光 / 底光 / 硬光 / 柔光 |
| 6 | **氛围情绪** | 画面传达的整体情绪 | 紧张 / 温馨 / 压抑 / 明快 / 诡异 / 孤独 / 释然 |

### B. 人物描述 (Character — 5 elements)

| # | 元素 | 说明 | 可选值示例 |
|---|------|------|-----------|
| 7 | **人物位置** | 人物在画面中的位置 | 左三分线 / 中央 / 右侧 / 画面底部 / 画面边缘 |
| 8 | **人物朝向** | 人物面部和身体的朝向 | 正面 / 四分之三侧面 / 侧面 / 背面 + 视线方向 |
| 9 | **姿态动作** | 人物的身体姿态和正在执行的动作 | 站立 / 坐姿 / 蹲下 / 前倾 / 伸手触碰 / 回头 |
| 10 | **表情眼神** | 面部表情 + 眼神方向和情绪 | 眉头微蹙、眼神专注 / 眼睛睁大、嘴唇微张 / 目光低垂、神情释然 |
| 11 | **人物关系** | 多人场景中人物的空间关系 | 对峙 / 并排 / 前后 / 围绕 / 背对背 |

### C. 空间层次 (Spatial Depth — 4 elements)

| # | 元素 | 说明 | 可选值示例 |
|---|------|------|-----------|
| 12 | **前景元素** | 画面前景的物体或框架 | 前景镜框 / 虚化植物 / 前景烟雾 / 无 |
| 13 | **中景主体** | 主要活动区域的内容 | 归档者和镜面 / 桌面上的五边形回路 |
| 14 | **背景环境** | 背景空间的描述 | 工作室墙面虚焦 / 递归层级延伸 / 黑暗空间 |
| 15 | **景深效果** | 焦点范围和虚化程度 | 浅景深（主体清晰背景虚化）/ 中景深 / 深景深（全画面清晰）|

### D. 光影色彩 (Light & Color — 4 elements)

| # | 元素 | 说明 | 可选值示例 |
|---|------|------|-----------|
| 16 | **光源方向** | 主光源照射的方向 | 从左侧照来 / 从顶部照来 / 从背后照来 / 从右下方照来 |
| 17 | **光影效果** | 阴影形态和高光位置 | 右侧脸颊柔和高光 / 地面长影 / 轮廓光勾勒 |
| 18 | **色温** | 光源的色温 | 冷白 5500K / 琥珀色暖光 3200K / 混合色温 |
| 19 | **色调对比** | 画面整体色彩倾向 | 冷蓝灰调 / 暖橙调 / 低饱和 / 高对比 |

### E. 技术风格 (Technical & Style — 3 elements)

| # | 元素 | 说明 | 可选值示例 |
|---|------|------|-----------|
| 20 | **焦距镜头** | 模拟的镜头焦距 | 广角 24mm / 标准 50mm / 长焦 85mm / 人像 85mm |
| 21 | **画幅比例** | 画面宽高比 | 16:9 / 21:9 / 9:16 / 4:3 |
| 22 | **质感风格** | 画面的视觉质感 | 胶片颗粒 / 梦核 / 超写实 / 电影感 / 赛博朋克 |

### F. 相对位置关系 (Relative Positioning — 4 elements)

| # | 元素 | 说明 | 可选值示例 |
|---|------|------|-----------|
| 23 | **人物与环境距离** | 人物和环境元素的空间关系 | 距镜面约 30cm / 站在空间中央 / 被镜面从四面包围 |
| 24 | **人物与人物关系** | 多人场景中的距离和朝向 | 两人相距约 2 米 / 面对面站立 / 视线交汇于中央 |
| 25 | **物品与空间关系** | 道具在空间中的位置和比例 | 五边形回路置于桌面中央 / 巨大镜框占据画面 2/3 |
| 26 | **视觉引导线** | 引导观众视线的构图线条 | 手臂指向镜面形成引导线 / 递归层级形成纵深引导 |

## 必备 vs 可选元素

### 所有帧图必备（7 项）

| 元素 | 说明 |
|------|------|
| 景别 | 确定画面范围 |
| 机位角度 | 确定拍摄视角 |
| 方位构图 | 确定主体位置 |
| 光线类型 | 确定光照条件 |
| 人物位置 | 确定人物在画面中的位置 |
| 人物朝向 | 确定人物面向方向和视线 |
| 姿态动作 | 确定人物的身体状态 |

### 近景 / 特写额外必备（+3 项）

| 元素 | 说明 |
|------|------|
| 表情眼神 | 近景/特写中面部是重点 |
| 光源方向 | 面部光影需要精确 |
| 光影效果 | 面部高光和阴影位置 |

### 多人场景额外必备（+2 项）

| 元素 | 说明 |
|------|------|
| 人物关系 | 多人空间关系 |
| 人物与人物关系 | 距离和视线交汇 |

### 全景 / 远景额外必备（+4 项）

| 元素 | 说明 |
|------|------|
| 前景元素 | 建立空间层次 |
| 背景环境 | 交代环境信息 |
| 景深效果 | 确定虚实关系 |
| 人物与环境距离 | 确定人物在空间中的位置 |

### 始终推荐（提升质量）

| 元素 | 说明 |
|------|------|
| 色温 | 统一画面色彩基调 |
| 色调对比 | 确定画面色彩风格 |
| 画幅比例 | 确定输出尺寸 |
| 质感风格 | 确定视觉风格 |

## 相对位置描述规范

### 人物与环境

- **距离**："距镜面约 30cm" / "站在空间中央" / "靠近窗边"
- **层次**："前景镜框，中景归档者，背景递归层级"
- **包围**："被镜面从四面包围" / "置身于开阔空间"

### 人物与人物

- **距离**："两人相距约 2 米" / "面对面站立"
- **对峙**："归档者与昨天的他对视" / "背对背站立"
- **视线**："两人视线交汇于中央" / "各自看向不同方向"

### 物品与空间

- **位置**："五边形回路置于桌面中央" / "照片扣在桌角"
- **比例**："巨大镜框占据画面 2/3" / "微型装置仅占画面 1/10"
- **关系**："镜子悬挂于墙面" / "回路漂浮于空中"

### 视觉引导线

- **视线引导**："归档者的视线从左下指向右上镜面"
- **构图引导**："桌面边缘形成水平引导线"
- **纵深引导**："递归层级形成由近及远的纵深引导"

## 帧图描述示例

### 示例：中景 + 单人 + 工作室场景

> 以归档者为参考的中景画面。**平视**，**四分之三侧**角度。归档者**站在镜面前**，身体**略微前倾**，右手伸向墙上镜面，指尖贴在镜面上。**面部朝向镜面，眼神专注，眉头微蹙**。镜面呈现同心圆涟漪纹路从触碰点向外扩散。
>
> 冷白光**从左侧照来**，照亮手指和镜面，**在归档者右侧脸颊形成柔和高光**。中央构图，浅景深，镜面居画面中心，**背景工作室墙面虚焦**。
>
> **前景：无；中景：归档者和镜面；背景：工作室墙面（虚焦）。**
> **归档者距镜面约 30cm，身体与镜面呈 45 度角。**
>
> 低饱和冷蓝灰调，色温冷白 5500K，轻微胶片颗粒，16:9 画幅。

**元素覆盖**：景别✓ 机位角度✓ 构图✓ 光线✓ 人物位置✓ 朝向✓ 姿态✓ 表情✓ 光源方向✓ 光影效果✓ 前中背景✓ 景深✓ 色温✓ 色调✓ 画幅✓ 质感✓ 人物与环境距离✓ — 共 17/26 项（中景单人场景的完整覆盖）

### 示例：全景 + 多人 + 奇幻场景

> 全景画面。**俯拍 30 度**角度。归档者**站在递归嵌套空间中央**，四周是无限延伸的镜面层级。**昨天的他**站在归档者**正前方约 3 米处**，**两人面对面，视线交汇**。归档者**双手自然下垂，身体微微后仰**，面露**惊讶，眼睛睁大**。昨天的他**双臂交叉于胸前，表情平静，目光直视归档者**。
>
> 冷白光**从顶部照来**，在两人脚下形成短影。**前景：最近一层镜面边框（虚化）；中景：归档者和昨天的他；背景：递归镜面层级无限延伸。** 深景深，全画面清晰。
>
> **归档者被镜面从四面包围，距最近镜面约 1.5 米。两人相距约 3 米，面对面站立。递归层级从中景向背景无限延伸，形成纵深引导线。**
>
> 低饱和冷蓝灰调，色温冷白 5500K，高对比，轻微胶片颗粒，16:9 画幅。

**元素覆盖**：景别✓ 机位角度✓ 构图✓ 光线✓ 人物位置✓ 朝向✓ 姿态✓ 表情✓ 人物关系✓ 光源方向✓ 光影效果✓ 前中背景✓ 景深✓ 色温✓ 色调✓ 画幅✓ 质感✓ 人物与环境距离✓ 人物与人物关系✓ 视觉引导线✓ — 共 20/26 项（全景多人场景的完整覆盖）
