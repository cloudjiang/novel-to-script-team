# 11a. Seedance 2.0 提示词方法论

## 概述

本文档整合三大 AI 视频生成提示词体系：
- **Seedance 2.0 提示词方法论**：文生视频，叙事描述式，支持多素材引用
- **Gemini 图像生成提示词**：文生图，影视分镜风格，叙事优先
- **图生视频动态提示词**：图生视频，聚焦动作变化，简洁高效

三者配合使用，覆盖从静态参考图生成到动态视频生成的完整工作流。

---

## 第一部分：Seedance 2.0 提示词方法论

### 第一性原则

#### 导演意图优先
- 导演讲戏本是创意源头，提示词是技术翻译
- 不偏离导演画面意图，不自行添加未描述内容
- 分镜师可补充技术细节（如运镜），但必须服务于导演叙事意图

#### 叙事描述式
- Seedance 2.0 擅长理解长段叙事性描述
- 用完整段落描述，像写电影脚本
- 不用关键词堆叠，不用标签式描述

#### 参考图已见原则
- Seedance 2.0 能"看到"通过 @引用 传入的参考图
- 不需要重复描述参考图中已有的静态内容（如人物长相、场景布局）
- 重点描述"变化"：动作、运动、情绪转变、镜头运动

#### 一条提示词一段叙事
- 每条提示词对应一次生成任务，产出一条视频
- 一条提示词内可包含多组镜头（如蒙太奇、连续切换），但叙事上必须连续
- 不在一条提示词中塞入叙事上不相关的场景

#### 节拍密度约束
作用于每个连续镜头内，非整段：
- 底层规律：1 拍 ≈ 2.5 秒屏幕时间
- 节拍太密，AI 生成的动作会糊、跳、不自然
- 多镜头段落的节拍分布在各镜头切换中，每个镜头各自遵守密度约束，总节拍可超单镜头上限

#### 头尾安全区
每次 Seedance 生成的前 0.5s 和后 0.5s 为安全区，不放关键内容：
- 开头：先给环境或主体一个静态建立
- 结尾：让动作自然收住或保持可衔接的姿态

### 视觉生成规范

#### 分镜草图风格（Storyboard Sketch Style）
- **默认风格**：Cinematic storyboard sketch, rough pencil style, black and white（电影感分镜草图，粗犷铅笔风格，黑白）
- **用途**：快速分镜可视化，聚焦构图和叙事，不受色彩干扰
- **适用场景**：Beat Board、Sequence Board 的初步可视化

#### 去情感化描述原则（De-Emotionalized Description）
- **核心原则**：禁止使用"悲伤"、"快乐"、"愤怒"等抽象情绪形容词
- **转化方法**：将情绪转化为可视化的视觉语言
  - ❌ "悲伤" → ✅ "阴影遮住眼睛，肩膀下垂"
  - ❌ "快乐" → ✅ "嘴角上扬，眼睛微眯"
  - ❌ "愤怒" → ✅ "眉头紧锁，拳头握紧，青筋暴起"
- **理由**：AI 无法直接理解抽象情绪，必须通过具体的视觉元素传达

#### 构图逻辑（Framing Logic）

**空间主导（Space-Dominant）**：
- 强调环境、场景、空间关系
- 人物在画面中占比较小，环境信息丰富
- 适用场景：建立镜头、环境展示、氛围营造

**角色主导（Character-Dominant）**：
- 强调人物表情、动作、情绪
- 人物在画面中占主要位置，背景简化
- 适用场景：情绪特写、对话场景、角色塑造

**关系主导（Relation-Dominant）**：
- 强调人物之间的空间关系、互动、对峙
- 构图平衡多个主体，突出相对位置
- 适用场景：对话、冲突、群戏

#### 运镜逻辑（Camera Behavior）

**固定镜头（Static）**：
- 镜头完全静止，无任何运动
- 适用场景：稳定、庄重、观察性镜头

**缓慢推拉（Slow Push/Pull）**：
- 缓慢推近或拉远，节奏平稳
- 适用场景：情绪积累、悬念建立、氛围营造

**手持感（Handheld）**：
- 模拟手持摄影的轻微晃动
- 适用场景：真实感、紧张感、纪录片风格

### Seedance 2.0 十大核心能力

#### 1. 纯文本生成（无参考素材）

最基础的用法，仅靠文字描述生成视频，无需上传任何素材。

**提示词模式**：
```
(主体描述) + (动作序列) + (环境/光影) + (镜头语言) + (风格关键词)
```

**示例**：
```
镜头跟随黑衣男子快速逃亡，后面一群人在追，镜头转为侧面跟拍，人物惊慌撞倒路边的水果摊爬起来继续逃，人群慌乱的声音。
```

#### 2. 一致性控制（角色/产品/场景统一）

通过上传参考图片保持人物、商品、场景的一致性。

**提示词模式**：
```
[角色]@图片N + [动作/剧情描述] + [场景]@图片N + [运镜/光影]
```

**示例**：
```
男人@图片1下班后疲惫的走在走廊，脚步变缓，最后停在家门口，脸部特写镜头，男人深呼吸，调整情绪，收起了负面情绪，变得轻松，然后特写翻找出钥匙，插入门锁，进入家里后，他的小女儿和一只宠物狗，欢快的跑过来迎接拥抱，室内非常的温馨，全程自然对话
```

**双锚一致性质量控制清单**（来自恒像师系统）：

检查点：
- [ ] 所有镜头中的角色外貌描述完全一致
- [ ] 所有镜头中的环境锚点保持一致
- [ ] 中英文提示词语义完全对应
- [ ] 允许变化严格限制在"姿态/表情/光照/天气"范围内
- [ ] 技术参数保持一致

原则：
1. **锚点重复**：角色和环境的固定元素必须在每个镜头中反复出现
2. **受控变化**：仅限于姿态、表情、光线、天气等非核心特征
3. **语义统一**：使用相同的词汇描述角色与环境锚点
4. **参数统一**：保持相同参数以确保风格和比例稳定

一致性标准：

**必须保持一致**：
- 角色：性别、年龄、外貌、发型、服装、标志元素
- 环境：建筑结构、地标位置、家具/自然元素、核心道具

**允许变化**：
- 角色：动作、表情、手势、角度
- 环境：光线、天气、氛围色彩、镜头视角

#### 3. 运镜与动作精准复刻

上传参考视频，复刻其中的镜头语言、复杂动作、节奏变化。

**提示词模式**：
```
参考@视频1的[运镜/动作/节奏] + [主体]@图片N + [场景描述]
```

**示例**：
```
参考@图1的男人形象，他在@图2的电梯中，完全参考@视频1的所有运镜效果还有主角的面部表情，主角在惊恐时希区柯克变焦，然后几个环绕镜头展示电梯内视角，电梯门打开，跟随镜头走出电梯，电梯外场景参考@图片3，男人环顾四周
```

#### 4. 创意模板/特效复刻

照着参考视频模仿创意转场、广告成片、电影片段、复杂剪辑。

**提示词模式**：
```
参考@视频1的[特效/转场/创意] + 将[元素]替换为@图片N + [补充说明]
```

**示例**：
```
将@视频1的人物换成@图片1，@图片1为首帧，人物带上虚拟科幻眼镜，参考@视频1的运镜，及近的环绕镜头，从第三人称视角变成人物的主观视角，在AI虚拟眼镜中穿梭，来到@图片2的深邃的蓝色宇宙，出现几架飞船穿梭向远方，镜头跟随飞船穿梭到@图片3的像素世界
```

#### 5. 剧情创作/补全

模型具备强大的创意性和剧情补全能力，可根据图片或分镜脚本自动生成剧情。

**提示词模式**：
```
[分镜脚本/图片内容描述] + [演绎方式] + [音效/台词要求]
```

**示例**：
```
将@图1以从左到右从上到下的顺序进行漫画演绎，保持人物说的台词与图片上的一致，分镜切换以及重点的情节演绎加入特殊音效，整体风格诙谐幽默；演绎方式参考@视频1
```

#### 6. 视频延长

对已有视频进行平滑延长，可向前或向后延长。

**提示词模式**：
```
将@视频1延长[X]s + [新增内容描述]
延长@视频1 + [详细的画面分段描述]
向前延长[X]s + [前置剧情描述]
```

**示例**：
```
将@视频1延长15秒。1-5秒：光影透过百叶窗在木桌、杯身上缓缓滑过，树枝伴随着轻微呼吸般的晃动。6-10秒：一粒咖啡豆从画面上方轻轻飘落，镜头向咖啡豆推进至画面黑屏。11-15秒：英文渐显第一行"Lucky Coffee"，第二行"Breakfast"，第三行"AM 7:00-10:00"。
```

#### 7. 声音控制

支持音色参考、对白生成、音效设计。

**提示词模式**：
```
[画面描述] + 音色/旁白参考@视频1 + [台词内容用引号标注]
```

**示例**：
```
固定镜头，中央鱼眼镜头透过圆形孔洞向下窥视，参考视频1的鱼眼镜头，让@视频2中的马看向鱼眼镜头，参考@视频1中的说话动作，背景BGM参考@视频3中的音效。
```

#### 8. 一镜到底

生成连贯的长镜头，镜头不切换，从一个场景平滑过渡到另一个场景。

**提示词模式**：
```
一镜到底 + @图片1@图片2@图片3... + [连续场景描述] + 全程不要切镜头
```

**示例**：
```
谍战片风格，@图片1作为首帧画面，镜头正面跟拍穿着红风衣的女特工向前走，镜头全景跟随，不断有路人遮挡红衣女子，走到一个拐角处，参考@图片2的拐角建筑，固定镜头红衣女子离开画面，走在拐角处消失，一个戴面具的女孩在拐角处躲着恶狠狠的盯着她，面具女孩形象参考@图片3。镜头往前摇向红衣女特工，她走进一座豪宅消失不见了，豪宅参考@图片4。全程不要切镜头，一镜到底。
```

#### 9. 视频编辑

基于已有视频进行定向修改：角色替换、剧情颠覆、元素增减。

**提示词模式**：
```
将@视频1中的[A]换成@图片1 + [其他修改说明]
颠覆@视频1的剧情 + [新剧情描述]
```

**示例**：
```
视频1中的女主唱换成图片1的男主唱，动作完全模仿原视频，不要出现切镜，乐队演唱音乐。
```

#### 10. 音乐卡点

让画面节奏与音乐节拍精准匹配。

**提示词模式**：
```
@图片1@图片2...@图片N + 参考@视频1的画面节奏/卡点 + [画面风格说明]
```

**示例**：
```
@图片1@图片2@图片3@图片4@图片5@图片6@图片7中的图片根据@视频中的画面关键帧的位置和整体节奏进行卡点，画面中的人物更有动感，整体画面风格更梦幻，画面张力强，可根据音乐及画面需求自行改变参考图的景别，及补充画面的光影变化
```

### 生成模式选型

Seedance 2.0 支持四种生成模式，各有最佳适用场景。分镜师在编写提示词时必须为每条选择合适的模式。

#### 四种模式定义

| 模式 | 标识 | 锁住什么 | 最擅长 | 需要额外帧图 |
|------|------|---------|--------|------------|
| T2V 文生 | `T2V` | 方向/氛围 | 灵感式镜头、纯环境 | 不需要 |
| I2V 首帧 | `I2V-首帧` | 开场构图 | 硬切换景别/机位 | 需要 1 张首帧图 |
| 首尾帧 | `首尾帧` | A→B过渡 | 连续动作、无缝转场 | 需要首帧图 + 尾帧图 |
| 多参考 | `多参考` | 一致性 | 角色稳定、风格统一 | 视情况 |

模式可叠加：`I2V-首帧 + 多参考`、`首尾帧 + 多参考`（帧图占 @图片配额）。

#### 选型决策树

按优先级从高到低判断：
1. 需要精确 A→B 画面过渡（连续动作、无缝转场）？→ `首尾帧`（+生成首帧图和尾帧图）
2. 需要精确控制开场构图（硬切换景别/机位）？→ `I2V-首帧`（+生成首帧图）
3. 涉及多角色/场景一致性？→ `多参考`
   - 追加判断：≥ 8s 且多时段画面差异大？→ 需要分镜参考图
4. 纯氛围/概念镜头？→ `T2V`
5. 默认 → `多参考`

#### 帧图类型与引用语法

| 类型 | 用途 | 引用语法 | 生成模式 |
|------|------|---------|---------|
| 首帧图 | I2V-首帧模式，锁定开场构图 | `@图片N 作为首帧` | I2V-首帧 / 首尾帧 |
| 尾帧图 | 首尾帧模式，锁定结束画面 | `@图片N 作为尾帧` | 首尾帧 |
| 分镜参考图 | 多参考模式多时段，引导各时段画面 | `参考分镜图@图片N` | 多参考（多时段） |

帧图统一输出到 `03-frame-requests.md`，由 image-generator 生成。

#### 帧图配额计算

帧图占 @图片 的 9 张配额。叠加模式下需计算总引用数：
- `I2V-首帧 + 多参考`：首帧图 1 张 + 角色/场景参考图 N 张 ≤ 9
- `首尾帧 + 多参考`：首帧图 1 张 + 尾帧图 1 张 + 参考图 N 张 ≤ 9
- `多参考 + 分镜参考图`：角色/场景参考图 + 分镜参考图总数 ≤ 9

#### 多参考模式下的分镜参考图

当一条提示词 ≥ 8s 且包含多个时间段时，各时段画面差异可能很大。Seedance 2.0 支持为每个时段指定不同参考图。

**判断规则**：
- 单时段（≤ 5s，无时间戳分段）→ 用现有角色/场景/物品参考图即可
- 多时段（≥ 8s，有 `0-3秒/4-6秒/...` 分段）：
  - 各时段画面差异小（同场景同人物仅动作变化）→ 不需要额外分镜图
  - 各时段画面差异大（换场景/换构图/换景别）→ 每个关键时段需要一张分镜参考图

#### 提示词输出格式（含模式标注）

```
**时长**：5s | **引用**：@图片1, @图片12, @图片21(首帧)
**生成模式**：I2V-首帧 + 多参考 | **选型理由**：硬切换景别
**帧图需求**：首帧（F01）
```

```
**时长**：10s | **引用**：@图片3, @图片6, @图片19, @图片22(分镜0-3s), @图片23(分镜4-7s), @图片24(分镜7-10s)
**生成模式**：多参考 | **选型理由**：多时段画面差异大，需分镜参考图引导
**帧图需求**：分镜参考图（F05, F06, F07）
```

### 平台约束

#### 输入限制（单条提示词 / 单次生成任务维度）

| 输入类型 | 数量上限 | 支持格式 | 大小限制 |
|---------|---------|---------|---------|
| 图片 | ≤ 9 张 | jpeg、png、webp、bmp、tiff、gif | 每张 < 30 MB |
| 视频 | ≤ 3 个 | mp4、mov | 每个 < 50 MB，总时长 2-15s |
| 音频 | ≤ 3 个 | mp3、wav | 每个 < 15 MB，总时长 ≤ 15s |
| 文本 | 自然语言提示词 | — | — |
| **总文件数** | **≤ 12 个** | — | — |

注意：以上限制是每条提示词（每次 Seedance 生成）的限制，不是全文档限制。素材对应表是全文档的总映射表，@图片 总数可以超过 9 张。

#### 输出参数
- 生成时长：4-15 秒（可自由选择）
- 自带音效/配乐
- 视频总像素数范围：480p（640×640）至 720p（834×1112）

#### 内容限制
- 不支持写实真人脸部素材（图片和视频均不可），系统会自动拦截
- 优先上传对画面或节奏影响最大的素材，合理分配文件数量

### @ 引用语法

#### 引用方式
```
@图片1    @图片2    @图片3   ...（最多9张）
@视频1    @视频2    @视频3   （最多3个）
@音频1    @音频2    @音频3   （最多3个）
```

#### 用途指定
务必明确说明每个引用的作用，不要只写"参考@视频1"而不说参考什么：

| 用途 | 示例写法 |
|------|---------|
| 首帧 | @图片1 作为首帧 |
| 尾帧 | @图片2 作为尾帧 |
| 人物形象 | 参考 @图片1 的人物形象 |
| 场景/背景 | 场景参考 @图片3 |
| 运镜 | 参考 @视频1 的运镜效果 |
| 动作 | 参考 @视频1 的动作编排 |
| 特效 | 完全参考 @视频1 的特效和转场 |
| 节奏/节拍 | 视频节奏参考 @视频1 |
| 音色/语气 | 旁白音色参考 @视频1 |
| 背景音乐 | 背景BGM参考 @音频1 |
| 音效 | 音效参考 @视频3 的音效 |
| 服装 | 穿着 @图片2 的服装 |

#### 多引用组合
可以在一条提示词中组合多个引用：
```
@图片1 的人物作为主角，参考 @视频1 的运镜和动作编排，
背景BGM参考 @音频1，场景参考 @图片5
```

#### 场景引用说明
scene-prompts.md 中的九宫格是"生成格式"，用于一次性生成所有场景的参考图。生成后，用户会将九宫格中的每个格子单独提取出来，作为独立的场景参考图。因此在素材对应表中，每个场景必须独立编号为一个 @图片，不能将整张九宫格作为一个 @图片。

正确示例（4 个人物 + 9 个场景）：
| 引用编号 | 素材类型 | 对应素材 |
|---------|---------|---------|
| @图片1 | 人物参考 | 林书白 |
| @图片2 | 人物参考 | 幼年林书白 |
| @图片3 | 人物参考 | 楚讲师 |
| @图片4 | 人物参考 | 考核长老 |
| @图片5 | 场景参考 | 简陋住处（室内）——九宫格格1 |
| @图片6 | 场景参考 | 青云文院大门——九宫格格2 |
| @图片7 | 场景参考 | 觉醒仪式大殿——九宫格格3 |
| ... | ... | ... |

错误示例：
| @图片5 | 场景参考 | ep01 场景宫格（整张九宫格）|
← 不要这样做，用户无法将整张九宫格上传为一个参考图

### 提示词结构

#### 基本结构
1. 素材引用声明（开头）
2. 场景/环境描述
3. 主体动作与运镜
4. 光影/氛围/声音
5. 风格/技术参数（可选）

#### 分时段描述（10秒以上推荐使用）
当生成时长 ≥ 10 秒时，推荐按时间段精确控制画面内容：

```
0-3秒：[开场画面描述、运镜、动作]
3-6秒：[中段发展]
6-10秒：[高潮或关键动作]
10-15秒：[收尾、定格画面]
```

分时段描述与节拍密度约束配合使用：
- 每个时间段内的动作密度不要超载
- 时间段之间的衔接要自然
- 多镜头段落中，每个时间段可对应不同的子场景/镜头
- 头尾安全区规则仍然适用（首段开头0.5s、末段结尾0.5s）

#### 完整示例
```
以@图片1中的林薇为主角，场景参考@图片3的深夜办公室。
中景，林薇独自坐在工位前，冷白荧光灯照亮她疲惫的面容。
她揉了揉太阳穴，目光从电脑屏幕缓缓移开，身体靠向椅背。
视线转向窗外，城市灯火稀落。她轻轻叹了口气，低声自语："又是一个人。"
镜头从她的侧脸慢慢推向窗外的夜色，整体氛围冷寂孤独，电影感。
```

#### 分时段示例（15秒）
```
以@图片1中的林薇为主角，场景参考@图片3的深夜办公室。
0-3秒：远景建立，空旷的办公区只有角落一盏台灯亮着，林薇的剪影映在落地窗上。
4-8秒：中景推近，林薇揉太阳穴，目光从屏幕移开，身体缓缓靠向椅背，表情从专注转为疲惫。
9-12秒：特写她的侧脸，视线转向窗外，城市灯火稀落，轻声自语："又是一个人。"
13-15秒：镜头缓慢拉远，林薇的身影在空旷办公区中越来越小，画面定格。
音效：键盘声渐弱、空调低鸣、窗外远处的车流声。电影感，冷寂孤独。
```

### 运镜词汇

#### 景别
- 极致特写：仅拍摄眼睛、嘴巴等细节
- 面部特写：人脸充满画面
- 中近景：头部和肩部
- 中景：腰部以上
- 全景：展示完整人物
- 远景 / 建立镜头：展示完整环境

#### 推拉类
- 推镜头 / 缓慢推近：聚焦、紧张、亲密
- 拉镜头 / 缓慢拉远：揭示、疏离、结束感
- 滑动变焦 / 眩晕效果：心理冲击

#### 横纵摇类
- 左摇 / 右摇：环顾、跟随水平运动
- 上摇 / 下摇：强调高度、规模
- 快速横摇：转场、惊讶

#### 环绕类
- 环绕主体：立体感、动感
- 弧形运动：戏剧性、强调
- 半环绕（180度）：对话、对峙

#### 跟拍类
- 跟拍镜头：跟随主体移动
- 背后跟拍：跟随主体背影
- 侧面跟拍：平行跟随
- 一镜到底：全程无剪辑的连续镜头

#### 升降类
- 上升镜头：史诗感、希望
- 下降镜头：压迫、沉重
- 航拍镜头：规模、全景

#### 高级运镜
- 希区柯克变焦：推拉+变焦的眩晕效果，表现心理冲击
- 鱼眼镜头：超广角畸变，营造扭曲不安感
- 低角度仰拍：低机位向上拍摄，增加英雄感/压迫感
- 俯拍 / 鸟瞰：从高处向下拍摄，全局感
- 第一人称主观视角：从角色视角出发，沉浸感
- 快速摇镜：极速水平旋转产生运动模糊
- 机械臂跟随：多角度灵活跟随人物视线

#### 手持与固定
- 手持镜头：真实感、紧张
- 固定机位：稳定、庄重

### 超长视频分段拼接策略

当用户需要超过15秒的视频时，采用**分段生成+视频延长拼接**的方式：

**核心原理**：先生成第一段视频（≤15秒），然后用「视频延长」功能，将上一段生成的视频作为输入，接续生成下一段内容。每次延长的时长就是新增部分的时长。

**分段规则**：
1. 将总时长按叙事节奏切分为多个片段，每段≤15秒
2. 每段之间必须有**画面衔接点**：上一段的结尾状态 = 下一段的开始状态
3. 第一段正常生成，后续每段使用「将@视频1延长Xs」的格式
4. 每段都要标注清楚属于整体的第几段、承接内容是什么

**输出格式**：
```
## 超长视频提示词（总时长约Xs）

**主题**：[一句话概括]
**总段数**：[N段]
**建议比例**：[16:9 / 9:16 / 1:1]

---

### 第1段（0-15秒）—— 正常生成

**生成时长**：15秒

#### 提示词

[完整提示词，时间戳分镜]

#### 衔接点

本段结尾画面：[精确描述结尾画面状态，用于下一段衔接]

---

### 第2段（15-30秒）—— 视频延长

**操作**：将第1段生成的视频上传为@视频1
**生成时长**：15秒

#### 提示词

将@视频1延长15秒。[接续内容的时间戳分镜描述]

#### 衔接点

本段结尾画面：[精确描述结尾画面状态]
```

**分段时长建议**：

| 总时长 | 推荐分段 | 音频策略 |
|--------|----------|---------|
| 16-30秒 | 2段（首段15秒 + 延长段） | 可使用BGM，视频延长功能会自动延续 |
| 31-45秒 | 3段 | 可使用BGM，视频延长功能会自动延续 |
| 46-60秒 | 4段 | 可使用BGM，视频延长功能会自动延续 |
| 60-120秒 | 5-8段 | **推荐静音版本**（仅保留环境音和对白），后期统一配乐 |
| >120秒 | 拆分为独立场景 | **推荐静音版本**，后期统一配乐 |

**超长视频音频处理策略**（>60秒）：

**问题**：多段拼接时BGM会断开，即使使用"视频延长"功能，音乐连续性也难以保证

**解决方案**：生成静音版本 + 后期配乐
1. **生成阶段**：每段提示词都使用 `音效：保留环境音（雨声、脚步声、车声）和对白，不添加背景音乐`
2. **拼接阶段**：用剪辑软件拼接所有片段
3. **配乐阶段**：统一添加完整的BGM轨道（2-3分钟连续音乐）

**优点**：
- ✅ 音乐完全连贯，无断点
- ✅ 可自由选择BGM，不受生成限制
- ✅ 各段可并行生成，效率高
- ✅ 后期可精确控制音画同步

**示例——2分钟短剧静音版本**：

第1段（0-15秒）：
```
[画面描述]
音效：保留环境音（暴雨声、车声）和对白，不添加背景音乐
```

第2段（15-30秒）：
```
[画面描述]
音效：保留环境音（暴雨声、脚步声）和对白，不添加背景音乐
```

...（后续各段同样处理）

后期配乐：
- 使用剪映/PR/Final Cut等剪辑软件
- 添加完整的2分钟悲伤钢琴曲BGM轨道
- 调整音量平衡（对白清晰，BGM作为背景）

**示例——30秒仙侠短片分段**：

第1段（正常生成15秒）：
```
15秒仙侠镜头，0-5秒：俯拍云海翻涌中的仙山全景，镜头缓缓下推穿过云层；6-10秒：剑修站在山巅悬崖边，背对镜头，衣袍随风飘动，远处魔气升腾；11-15秒：剑修缓缓转身面向镜头，拔剑出鞘，剑刃金光闪烁，目光坚毅低声道"来了"，定格在剑修持剑面向镜头的画面。
```

第2段（视频延长15秒）：
```
将@视频1延长15秒。0-5秒：接上段剑修持剑画面，数十只暗影魔兽从远处魔气中飞扑而来，剑修纵身跃起迎敌；6-10秒：空中激战，剑气纵横，魔兽被斩成灰烬粒子消散，镜头环绕快切；11-15秒：剑修落地收剑，身后爆炸的金色粒子缓缓飘散，镜头缓推特写剑修侧脸，音效渐弱。
```

### 音频设计

### 从导演讲戏到提示词的转化步骤

1. **提取素材引用**
   - 从导演阐述的人物和场景字段，对应 character-prompts.md 和 scene-prompts.md 中的素材
   - 在提示词开头声明引用，明确每个引用的用途

2. **提取核心动作**
   - 从导演阐述中识别主要动作链
   - 保留具体物理动作，删除抽象描述

3. **提取运镜意图**
   - 从导演阐述中识别镜头运动描述
   - 转化为规范的运镜语言
   - 如果导演未明确指定运镜，根据情绪和叙事目的补充

4. **提取声音/台词**
   - 从导演阐述中提取对白、自语、环境音
   - 保持原文台词不变
   - 补充音效设计和背景音乐指导

5. **判断是否使用分时段描述**
   - 时长 ≥ 10 秒：推荐使用分时段描述
   - 时长 < 10 秒：使用连续段落描述即可

6. **整合为完整提示词**
   - 按照提示词结构组织
   - 确保叙述流畅、连贯
   - 控制在合理长度（与时长匹配）
   - 检查每个 @引用 都有明确的用途说明

### 禁忌规则

#### 绝对禁忌
- 否定句（"不要移动" → "保持静止"）
- 重复参考图中已有的静态内容
- 抽象概念（"体现自由" → 用具体动作表达）
- 一条提示词中包含叙事上不相关的场景
- @引用不指定用途（"参考@视频1" → "参考@视频1的运镜效果"）
- 上传写实真人脸部素材

#### 避免事项
- 过长提示词（控制信息密度与时长匹配）
- 违反物理规律的动作
- 与参考图内容矛盾的描述
- 指令冲突（同时要求"固定镜头"和"环绕镜头"）
- 单个连续镜头内节拍过密
- 素材上传了但提示词中未用 @ 标注用途
- 时长与内容密度不匹配

#### AI真人生成约束

AI真人视频生成对动作和场景有特殊限制，必须遵循以下约束：

**避免复杂肢体接触：**
- ❌ 拥抱、打斗、舞蹈、推搡、拉扯
- ✅ 对视、沉默、微表情、手势

**避免多人同框：**
- ❌ 超过2人同框（容易崩）
- ✅ 单人或双人对话场景

**避免快速动作切换：**
- ❌ 快速走位、跑动、跳跃
- ✅ 缓慢移动、静态情绪戏

**优先设计静态情绪戏：**
- ✅ 对视（眼神戏）
- ✅ 沉默（情绪压抑）
- ✅ 微表情变化（从冷漠到动容）
- ✅ 欲言又止（情绪拉扯）

**核心原则：** 动作越复杂，越容易崩。AI不像真实演员，写的时候就要考虑这场戏是不是能"稳定复现"。

#### 禁止项声明技巧

在提示词结尾声明不需要的元素，帮助模型规避常见问题：
```
禁止：
- 任何文字、字幕、LOGO或水印
- 不允许出现XXX
- 画面全部片段都不要出现字幕
```
