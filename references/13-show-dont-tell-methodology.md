# Show Don't Tell 方法论

## 核心原则

**第一性原则**：用动作和画面提升情绪，而不是模糊的情绪形容词。

**目标**：将抽象情绪翻译为可拍摄的视觉语言，让观众通过看到的画面感受情绪，而不是被告知情绪。

---

## 一、情绪形容词黑名单

### 1.1 禁用的情绪形容词

以下情绪形容词**禁止直接出现在剧本中**，必须翻译为动作或画面：

#### 基础情绪类
- ❌ 伤心、难过、悲伤、痛苦、心碎
- ❌ 开心、高兴、快乐、兴奋、激动
- ❌ 愤怒、生气、恼火、暴怒、愤恨
- ❌ 害怕、恐惧、惊恐、紧张、不安
- ❌ 惊讶、震惊、意外、诧异、惊愕

#### 复杂情绪类
- ❌ 失望、绝望、无助、无奈、迷茫
- ❌ 尴尬、羞愧、内疚、后悔、自责
- ❌ 嫉妒、羡慕、不甘、憋屈、委屈
- ❌ 冷漠、麻木、疲惫、厌倦、无聊
- ❌ 温柔、温暖、感动、心疼、怜惜

#### 状态描述类
- ❌ 紧张、焦虑、慌乱、不知所措
- ❌ 犹豫、纠结、矛盾、挣扎、动摇
- ❌ 坚定、果断、决绝、冷静、淡定
- ❌ 疲惫、虚弱、无力、崩溃、绝望

### 1.2 允许的网文感情绪词

以下网文感情绪词可以保留，因为它们已经成为类型化标记：

- ✅ 冷笑、嗤笑、冷哼、轻笑、讥笑
- ✅ 眼神一冷、目光一沉、脸色一变
- ✅ 嘴角上扬、眉头一挑、眼神闪烁

**注意**：这些词必须配合具体动作使用，不能单独出现。

## 二、动作情绪化翻译表

### 2.1 伤心/难过

| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| ❌ 她很伤心 | ✅ 她低头盯着手机屏幕，拇指悬在发送键上方，颤抖着，最终还是删掉了整段文字 | 特写：手指颤抖 + 删除动作 |
| ❌ 他难过极了 | ✅ 他靠在墙上，缓缓滑坐到地上，双手抱住膝盖，把脸埋进臂弯里 | 全景：滑坐动作 + 蜷缩姿态 |
| ❌ 她心碎了 | ✅ 她咬紧下唇，眼眶泛红，但强忍着没让泪水落下，转身快步离开 | 中景：咬唇 + 眼眶泛红 + 转身 |
| ❌ 他痛苦不堪 | ✅ 他双手撑在洗手台上，低着头，肩膀微微颤抖，水龙头的水一直流着 | 侧面中景：撑台 + 肩膀颤抖 + 流水 |

**设计原则**：
- 使用具体的身体动作（低头、咬唇、颤抖）
- 加入环境细节（手机、墙、洗手台）
- 强调克制和压抑（强忍、没让泪水落下）
- 避免直接流泪（太直白，缺乏张力）

### 2.2 愤怒/生气

| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| ❌ 他很愤怒 | ✅ 他猛地站起身，椅子被推得向后滑出一米，发出刺耳的摩擦声 | 全景：站起 + 椅子滑动 + 声音 |
| ❌ 她生气了 | ✅ 她把手中的文件重重摔在桌上，纸张散落一地，转身就走 | 中景：摔文件 + 纸张散落 + 转身 |
| ❌ 他暴怒 | ✅ 他握紧拳头，指节泛白，青筋暴起，盯着对方一字一顿："你、再、说、一、遍。" | 特写：拳头 + 指节泛白 + 青筋 |
| ❌ 她恼火极了 | ✅ 她深吸一口气，闭上眼睛，再睁开时眼神冰冷："出去。" | 中景：深呼吸 + 闭眼 + 眼神变化 |

**设计原则**：
- 使用爆发性动作（站起、摔、握拳）
- 加入声音元素（摩擦声、一字一顿）
- 强调身体细节（指节泛白、青筋暴起）
- 用短句台词增强情绪（"出去"、"你再说一遍"）

### 2.3 害怕/恐惧

| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| ❌ 她很害怕 | ✅ 她下意识后退一步，背抵住墙，双手紧紧攥着衣角，眼神不敢直视对方 | 中景：后退 + 抵墙 + 攥衣角 |
| ❌ 他恐惧不安 | ✅ 他的手不停地颤抖，试图拿起水杯，却两次都没拿稳，水洒了一桌 | 特写：颤抖的手 + 水杯 + 洒水 |
| ❌ 她惊恐万分 | ✅ 她瞳孔骤然放大，呼吸急促，想说话却发不出声音，只能张着嘴 | 特写：瞳孔 + 呼吸 + 张嘴无声 |
| ❌ 他紧张极了 | ✅ 他不停地搓着手，目光游移不定，额头渗出细密的汗珠 | 中景：搓手 + 游移目光 + 汗珠 |

**设计原则**：
- 使用防御性动作（后退、抵墙、攥衣角）
- 强调失控细节（颤抖、洒水、发不出声）
- 加入生理反应（瞳孔放大、呼吸急促、出汗）
- 避免尖叫（太直白，缺乏层次）

### 2.4 惊讶/震惊

| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| ❌ 她很惊讶 | ✅ 她手中的咖啡杯停在半空，眼睛微微睁大，盯着对方好几秒才反应过来 | 中景：杯子悬空 + 眼睛睁大 + 凝视 |
| ❌ 他震惊了 | ✅ 他正在签字的笔突然顿住，抬起头，眉头紧皱："你说什么？" | 特写：笔顿住 + 抬头 + 皱眉 |
| ❌ 她难以置信 | ✅ 她张了张嘴，想说什么却没说出来，最后只是摇了摇头 | 中景：张嘴 + 欲言又止 + 摇头 |
| ❌ 他目瞪口呆 | ✅ 他愣在原地，手机从手中滑落，掉在地上，他却毫无反应 | 全景：愣住 + 手机滑落 + 无反应 |

**设计原则**：
- 使用中断动作（杯子停住、笔顿住、手机滑落）
- 强调时间停滞感（好几秒、愣在原地）
- 加入欲言又止（张嘴、想说却没说）
- 用物品掉落增强冲击感

### 2.5 失望/绝望

| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| ❌ 她很失望 | ✅ 她看着对方，眼神从期待变得黯淡，最后垂下眼帘，轻声说："算了。" | 中景：眼神变化 + 垂眼 + 轻声 |
| ❌ 他绝望了 | ✅ 他无力地坐在椅子上，双手垂在身侧，目光空洞地盯着前方，一动不动 | 全景：无力坐姿 + 垂手 + 空洞目光 |
| ❌ 她心灰意冷 | ✅ 她把手中的戒指放在桌上，推向对方，起身离开，没有回头 | 中景：放戒指 + 推向对方 + 离开 |
| ❌ 他万念俱灰 | ✅ 他站在窗前，看着外面的雨，手指在玻璃上画了一个圈，又慢慢抹掉 | 侧面中景：窗前 + 雨 + 画圈 + 抹掉 |

**设计原则**：
- 使用放弃性动作（垂眼、垂手、放下、抹掉）
- 强调无力感（无力坐着、一动不动）
- 加入象征性物品（戒指、雨）
- 用"算了"、"没有回头"增强情绪

### 2.6 尴尬/羞愧

| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| ❌ 她很尴尬 | ✅ 她不自然地笑了笑，目光躲闪，手指无意识地绞着衣角 | 中景：不自然笑 + 躲闪目光 + 绞衣角 |
| ❌ 他羞愧难当 | ✅ 他低着头，双手紧握，指甲陷进掌心，一句话也说不出来 | 特写：低头 + 紧握 + 指甲陷入 |
| ❌ 她无地自容 | ✅ 她脸颊泛红，咬着下唇，转身快步离开，脚步有些慌乱 | 中景：脸红 + 咬唇 + 快步离开 |
| ❌ 他内疚不已 | ✅ 他张了张嘴，想解释什么，最后只是深深低下头："对不起。" | 中景：张嘴 + 欲言又止 + 低头 |

**设计原则**：
- 使用回避性动作（躲闪、低头、转身）
- 强调不自然感（不自然笑、慌乱脚步）
- 加入生理反应（脸红、咬唇）
- 用简短道歉增强情绪

### 2.7 犹豫/纠结

| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| ❌ 她很犹豫 | ✅ 她的手伸向门把手，停在半空，又缩了回来，如此反复三次 | 特写：手 + 门把手 + 反复动作 |
| ❌ 他很纠结 | ✅ 他来回踱步，时而看看手机，时而看看窗外，最后叹了口气 | 全景：踱步 + 看手机 + 看窗外 + 叹气 |
| ❌ 她左右为难 | ✅ 她拿起笔，在合同上悬停，咬着笔帽，眉头紧锁，迟迟没有落笔 | 特写：笔悬停 + 咬笔帽 + 皱眉 |
| ❌ 他举棋不定 | ✅ 他盯着两份文件，手指在两者之间来回移动，最后揉了揉太阳穴 | 中景：盯文件 + 手指移动 + 揉太阳穴 |

**设计原则**：
- 使用重复性动作（反复、来回、移动）
- 强调停滞感（悬停、迟迟没有）
- 加入焦虑细节（咬笔帽、揉太阳穴）
- 用叹气增强情绪

### 2.8 冷漠/麻木

| 情绪形容词 | 动作化翻译 | 画面语言 |
|-----------|-----------|---------|
| ❌ 她很冷漠 | ✅ 她看着对方，面无表情，眼神平静得像一潭死水，连眼皮都没眨一下 | 特写：面无表情 + 平静眼神 |
| ❌ 他麻木不仁 | ✅ 他机械地点了点头，目光从对方脸上滑过，落在远处的墙上 | 中景：机械点头 + 目光滑过 |
| ❌ 她无动于衷 | ✅ 她继续低头看着手机，手指滑动屏幕，对方说的话仿佛没听见 | 中景：低头看手机 + 滑屏 + 无反应 |
| ❌ 他冷若冰霜 | ✅ 他靠在椅背上，双手交叉抱胸，嘴角微微下压，一言不发 | 全景：靠椅背 + 抱胸 + 嘴角下压 |

**设计原则**：
- 使用机械性动作（机械点头、滑屏）
- 强调无反应（没眨眼、没听见、一言不发）
- 加入距离感（目光滑过、抱胸）
- 用"死水"、"冰霜"等隐喻增强感觉

## 三、画面语言设计原则

### 3.1 景别选择

| 情绪类型 | 推荐景别 | 原因 |
|---------|---------|------|
| 细腻情绪（伤心、失望） | 特写/大特写 | 捕捉微表情和细节 |
| 爆发情绪（愤怒、惊讶） | 中景/全景 | 展现肢体动作和空间关系 |
| 压抑情绪（冷漠、麻木） | 中景 | 保持距离感，强调隔阂 |
| 复杂情绪（犹豫、纠结） | 特写+全景交替 | 内心挣扎与外部环境对比 |

### 3.2 动作设计三原则

#### 原则1：具体化
- ❌ 她很紧张 → ✅ 她不停地搓着手
- ❌ 他很愤怒 → ✅ 他握紧拳头，指节泛白

#### 原则2：可拍化
- ❌ 她内心充满矛盾 → ✅ 她的手伸向门把手，又缩了回来
- ❌ 他感到绝望 → ✅ 他无力地坐在椅子上，目光空洞

#### 原则3：情绪化
- ❌ 她走了 → ✅ 她转身快步离开，没有回头
- ❌ 他坐下 → ✅ 他靠在墙上，缓缓滑坐到地上

### 3.3 环境细节增强法

通过环境细节增强情绪感染力：

| 情绪 | 环境细节 | 效果 |
|-----|---------|------|
| 伤心 | 水龙头一直流着、雨声、空荡荡的房间 | 增强孤独感 |
| 愤怒 | 椅子摩擦声、纸张散落、玻璃碎裂 | 增强爆发感 |
| 恐惧 | 昏暗灯光、阴影、寂静 | 增强压迫感 |
| 失望 | 窗外的雨、空咖啡杯、未接来电 | 增强无力感 |

## 四、视觉隐喻库

### 4.1 常用视觉隐喻

| 情绪/状态 | 视觉隐喻 | 使用场景 |
|----------|---------|---------|
| 关系破裂 | 戒指、照片、信件 | 分手、离婚、决裂 |
| 时间流逝 | 钟表、日历、窗外光线变化 | 等待、回忆、成长 |
| 内心挣扎 | 镜子、倒影、阴影 | 自我怀疑、身份认同 |
| 希望破灭 | 熄灭的烟、凋零的花、停止的钟 | 失望、绝望、放弃 |
| 压抑情绪 | 紧握的拳头、咬紧的牙、颤抖的手 | 愤怒、恐惧、悲伤 |

### 4.2 物品象征

| 物品 | 象征意义 | 使用示例 |
|-----|---------|---------|
| 戒指 | 承诺、关系 | 她把戒指放在桌上，推向对方 |
| 手机 | 联系、期待 | 他盯着手机屏幕，等待回复，但始终没有消息 |
| 照片 | 回忆、过去 | 她看着照片，手指轻轻抚过他的脸，最后撕成两半 |
| 钥匙 | 归属、家 | 他把钥匙放在门口的鞋柜上，转身离开 |
| 咖啡/酒 | 情绪宣泄 | 她端起酒杯，一饮而尽，眼眶泛红 |

## 五、实战检查清单

### 5.1 剧本自查（写作阶段）

在写作时，每写完一场戏，检查：

- [ ] 是否有情绪形容词黑名单中的词？
- [ ] 每个情绪是否都有对应的动作或画面？
- [ ] 动作是否具体、可拍、情绪化？
- [ ] 是否使用了环境细节增强情绪？
- [ ] 是否有视觉隐喻？

### 5.2 审核检查（审核阶段）

审核剧本时，重点检查：

#### 情绪形容词密度
- 统计情绪形容词出现次数
- 目标：每1000字 ≤ 2个（允许网文感情绪词）
- 超标则要求改写

#### 视觉化程度评分
- 动作描写占比 ≥ 30%
- 对话占比 ≥ 50%
- 纯叙述占比 ≤ 20%

#### 动作/画面比例
- 每个情绪转折必须有对应动作
- 每场戏至少3个具体动作
- 每场戏至少1个环境细节

### 5.3 改写流程

发现情绪形容词时：

1. **识别情绪类型**：伤心？愤怒？失望？
2. **查找翻译表**：找到对应的动作化翻译
3. **选择景别**：特写？中景？全景？
4. **加入细节**：环境细节？物品象征？
5. **验证可拍性**：能拍吗？清晰吗？情绪化吗？

## 六、进阶技巧

### 6.1 情绪对比法

通过前后对比增强情绪冲击：

**示例1：从期待到失望**
```
※ 她盯着手机屏幕，眼睛一眨不眨，嘴角微微上扬。
△ 屏幕亮起，她立刻点开消息。
※ 看清内容后，她的笑容僵住，手指停在屏幕上。
△ 她缓缓放下手机，眼神黯淡下来。
```

**示例2：从平静到爆发**
```
※ 他坐在沙发上，面无表情地听着对方说话。
△ 对方越说越激动，他却一动不动。
※ 突然，他猛地站起身，椅子被推得向后滑出一米。
△ "够了！"他的声音冰冷，眼神锐利。
```

### 6.2 情绪层次递进法

通过多层次动作展现情绪深度：

**示例：深度伤心**
```
第一层（表面克制）：
※ 她咬着下唇，眼眶泛红，但强忍着没让泪水落下。

第二层（身体反应）：
△ 她的手不自觉地握紧，指甲陷进掌心。

第三层（情绪爆发）：
※ 她转身快步离开，脚步越来越快，最后几乎是跑着离开的。

第四层（崩溃释放）：
△ 她靠在墙上，缓缓滑坐到地上，把脸埋进臂弯里，肩膀剧烈颤抖。
```

### 6.3 留白与克制

最高级的情绪表达是克制和留白：

**示例1：克制的愤怒**
```
❌ 他暴怒，大声吼叫
✅ 他深吸一口气，闭上眼睛，再睁开时眼神冰冷："出去。"
```

**示例2：克制的伤心**
```
❌ 她痛哭流涕
✅ 她咬紧下唇，眼眶泛红，但强忍着没让泪水落下，转身离开。
```

**原则**：压抑的情绪比爆发的情绪更有张力。

## 七、常见错误与修正

### 7.1 错误类型

#### 错误1：堆砌情绪形容词
```
❌ 她伤心、难过、痛苦、绝望，眼泪止不住地流下来。
✅ 她靠在墙上，缓缓滑坐到地上，把脸埋进臂弯里，肩膀微微颤抖。
```

#### 错误2：动作不具体
```
❌ 他很生气地走了
✅ 他猛地站起身，椅子被推得向后滑出一米，转身大步离开，门被重重关上。
```

#### 错误3：缺乏画面感
```
❌ 她内心充满矛盾
✅ 她的手伸向门把手，停在半空，又缩了回来，如此反复三次。
```

#### 错误4：过度文学化
```
❌ 此刻的我，内心充满了失望与愤怒，仿佛被千万根针刺穿。
✅ 她看着对方，眼神从期待变得黯淡，最后垂下眼帘，轻声说："算了。"
```

### 7.2 修正流程

1. **标记**：用荧光笔标记所有情绪形容词
2. **分类**：判断情绪类型（伤心/愤怒/失望等）
3. **翻译**：查找翻译表，选择合适的动作化表达
4. **增强**：加入环境细节或视觉隐喻
5. **验证**：检查是否具体、可拍、情绪化

## 十、成功指标

### 10.1 量化指标

- 情绪形容词密度：≤ 2个/1000字
- 动作描写占比：≥ 30%
- 对话占比：≥ 50%
- 每场戏具体动作数：≥ 3个
- 每场戏环境细节数：≥ 1个

### 10.2 质量指标

- 每个情绪都有对应的可拍动作
- 动作具体、清晰、情绪化
- 观众能通过画面感受情绪
- 无需旁白解释情绪

## 十一、烟火白描法（汪曾祺方法论）

> 来源：079-烟火白描法（2026-03-12 收编）

**核心心法**：闭上你的嘴，睁开你的眼。不说感受，只描写客观存在的场景和动作。

### 公式1：动词代替形容词

- ❌ "豆腐很嫩" → ✅ "用勺子轻轻一舀，颤巍巍的，还带着豆香"
- ❌ "风很大" → ✅ "风把晾在竹竿上的衬衫吹得鼓起来，衣袖啪嗒啪嗒地抽打着墙壁"
- ❌ "他很生气" → ✅ "他把手里的烟盒捏扁，指关节泛白，猛地砸进垃圾桶"
- **动词是画面的引擎**

### 公式2：颜色生活化（物证化）

- ❌ "晚霞很美" → ✅ "天边泛出柿黄色，一层一层晕开，渐渐淡成月白"
- ❌ "栀子花很白" → ✅ "栀子花的白，是那种糯米纸的白，薄薄的，透光的"
- **颜色要有物证，才有温度**

### 公式3：小镜头代替大叙事

- ❌ "母亲很辛苦" → ✅ "母亲坐在灶前，火光一跳一跳映在她脸上，她伸手把柴往里推了推"
- ❌ "父亲话少" → ✅ "他总是一个人坐在门槛上卷烟，卷好一支，凑到灯前点燃"
- **能打动人的只有细节，标签无法打动人**
