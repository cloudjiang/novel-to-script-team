# 18. 题材选择哲学

## 核心理念

**众生没有真理、真相，只有好恶，所以你才有价值。**

觉悟天道，是名开天眼。你需要的就是一双天眼，一双剥离了政治、文化、传统、道德、宗教之分别的眼睛，然后再如实观照政治、文化、传统，把被文化、道德颠倒的真理、真相颠倒过来，随便你怎么写怎么拍都是新意和深度，这就是钱，就是名利、成就、价值。

---

## 第一性原则：从人性本质出发

### 1. 众生只有好恶，没有真理

**核心洞察**：
- 人们不是被真理驱动，而是被情绪和偏好驱动
- 观众不关心"应该"，只关心"想要"
- 道德、文化、传统都是表象，人性本质才是底层

**题材选择启示**：
- 不要从"正确"出发，要从"触动"出发
- 不要问"这个题材有意义吗"，要问"这个题材触动人心吗"
- 不要追求"深刻"，要追求"共鸣"

**实操方法**：
```
错误路径：这个题材符合主流价值观吗？→ 安全但平庸
正确路径：这个题材触动人性本质吗？→ 危险但有价值
```

### 2. 开天眼：剥离分别

**三步法**：

#### 第一步：剥离
超越政治、文化、传统、道德、宗教的束缚

**具体操作**：
- 剥离政治：不问"政治正确"，问"人性真实"
- 剥离文化：不问"文化传统"，问"普世共鸣"
- 剥离道德：不问"道德高尚"，问"情感真实"
- 剥离宗教：不问"信仰正确"，问"人性困境"

**示例**：
```
传统视角：母爱是伟大的、无私的
剥离后：母亲也是人，也有私心、也有偏爱、也会犯错
题材价值：《逼我离开我成了道门天师你哭什么》中母亲偏心弟弟的真实人性
```

#### 第二步：观照
如实观照政治、文化、传统、道德、宗教

**具体操作**：
- 不是否定这些表象，而是看清它们的本质
- 不是批判这些规则，而是理解它们如何运作
- 不是逃避这些束缚，而是洞察它们如何影响人

**示例**：
```
观照对象：传统家庭伦理中的"孝道"
表面：子女应该孝顺父母
本质：父母用"孝道"绑架子女，满足自己的控制欲
题材价值：揭示"孝道"背后的权力关系和情感勒索
```

#### 第三步：颠倒
把被文化、道德颠倒的真理、真相颠倒过来

**具体操作**：
- 找到主流叙事中被掩盖的真相
- 揭示被美化的丑陋
- 暴露被合理化的不合理

**示例**：
```
主流叙事：母亲为了家庭牺牲自己，伟大无私
颠倒后：母亲把自己的失败归咎于子女，情感勒索
题材价值：《都挺好》中苏母的真实面目
```

## 题材价值判断标准

### 标准1：是否触及人性本质？

**判断方法**：
- 剥离所有文化、道德的包装，这个题材还剩下什么？
- 如果剩下的是"人性的欲望、恐惧、贪婪、爱恨"，那就是好题材
- 如果剩下的是"空洞的口号、说教、道德标签"，那就是坏题材

**案例对比**：
```
坏题材：一个好人做好事，最后得到好报
→ 剥离后：空洞的道德说教

好题材：一个人为了生存，不得不做坏事，最后陷入道德困境
→ 剥离后：人性的挣扎和困境
```

### 标准2：是否揭示被掩盖的真相？

**判断方法**：
- 这个题材是否挑战主流叙事？
- 这个题材是否揭示被美化的丑陋？
- 这个题材是否暴露被合理化的不合理？

**案例对比**：
```
主流叙事：母爱是伟大的
被掩盖的真相：有些母亲偏心、自私、情感勒索

主流叙事：努力就能成功
被掩盖的真相：阶层固化、资源垄断、机会不平等

主流叙事：爱情是纯洁的
被掩盖的真相：爱情中充满权力、控制、占有
```

### 标准3：是否有普世性和当下性？

**普世性**：
- 这个题材是否触动全球众生的情绪？
- 不同文化、不同国家的人是否都能共鸣？
- 是否触及人类共同的欲望、恐惧、困境？

**当下性**：
- 这个题材是否回应当下的社会焦虑？
- 是否触及当下人们最关心的问题？
- 是否提供当下人们最需要的情绪出口？

**案例**：
```
普世性：母亲偏心（全球共鸣）
当下性：35岁中年危机（当下焦虑）
普世性+当下性：阶层固化下的个体挣扎（全球当下共鸣）
```

### 标准4：是否触动全球众生的情绪？

**情绪判断**：
- 愤怒：不公、压迫、背叛
- 恐惧：失控、未知、死亡
- 悲伤：失去、遗憾、无力
- 喜悦：复仇、翻身、胜利
- 焦虑：不确定、危机、选择

**题材选择**：
- 优先选择能触发强烈情绪的题材
- 优先选择能触发多种情绪的题材
- 优先选择能触发普世情绪的题材

## 实际应用方法

### 方法1：识别"被颠倒的真相"

**步骤**：
1. 列出主流叙事中的"应该"
2. 问：现实中真的是这样吗？
3. 找到被掩盖的真相
4. 设计题材揭示这个真相

**示例**：
```
主流叙事：父母都是爱孩子的
现实真相：有些父母偏心、自私、把孩子当工具
题材设计：《逼我离开我成了道门天师你哭什么》

主流叙事：努力就能成功
现实真相：阶层固化、资源垄断、机会不平等
题材设计：《寒门再难出贵子》

主流叙事：爱情是纯洁的
现实真相：爱情中充满权力、控制、占有
题材设计：《追妻火葬场》
```

### 方法2：从"好恶"出发设计题材

**步骤**：
1. 问：观众最讨厌什么？（恶）
2. 问：观众最渴望什么？（好）
3. 设计题材：从"恶"到"好"的转变

**示例**：
```
观众最讨厌：被轻视、被羞辱、被背叛
观众最渴望：翻身、复仇、打脸
题材设计：废材逆袭、重生复仇、战神归来

观众最讨厌：不公、压迫、欺凌
观众最渴望：正义、反击、胜利
题材设计：弱者反击、底层逆袭、权力博弈
```

### 方法3：确保题材有普世性

**检查清单**：
- [ ] 这个题材是否触及人类共同的欲望？（权力、财富、爱情、尊严）
- [ ] 这个题材是否触及人类共同的恐惧？（死亡、失去、背叛、孤独）
- [ ] 这个题材是否触及人类共同的困境？（选择、道德、生存、身份）
- [ ] 不同文化背景的人是否都能理解和共鸣？

**反例**：
```
❌ 过于本土化：依赖特定文化背景才能理解的题材
❌ 过于小众：只有特定群体才能共鸣的题材
❌ 过于抽象：需要高度文化素养才能理解的题材
```

**正例**：
```
✅ 母亲偏心：全球共鸣
✅ 阶层固化：全球共鸣
✅ 爱情背叛：全球共鸣
✅ 权力压迫：全球共鸣
```

### 方法4：找到当下触动人心的内容

**当下焦虑清单**（2026年）：
- 35岁中年危机
- 阶层固化
- 原生家庭创伤
- 性别不平等
- 职场PUA
- 情感勒索
- 身份焦虑
- 存在焦虑

**题材设计**：
- 从当下焦虑出发，设计题材
- 提供情绪出口，而不是解决方案
- 让观众在故事中找到共鸣和释放

## 案例分析

### 案例1：《逼我离开我成了道门天师你哭什么》

**主流叙事**：母爱是伟大的、无私的
**被掩盖的真相**：有些母亲偏心、自私、把孩子当工具
**颠倒后的题材**：母亲偏心弟弟，逼走女儿，女儿成功后母亲后悔

**为什么有价值**：
- 触及人性本质：母亲的偏心和自私
- 揭示被掩盖的真相：母爱不一定伟大
- 普世性：全球共鸣（原生家庭创伤）
- 当下性：回应当下的原生家庭焦虑
- 触动情绪：愤怒（不公）+ 喜悦（复仇）

### 案例2：《都挺好》

**主流叙事**：父母都是爱孩子的
**被掩盖的真相**：有些父母重男轻女、情感勒索、道德绑架
**颠倒后的题材**：苏母重男轻女，苏明玉被迫独立，最后拒绝回家

**为什么有价值**：
- 触及人性本质：父母的自私和控制欲
- 揭示被掩盖的真相：孝道背后的情感勒索
- 普世性：全球共鸣（家庭矛盾）
- 当下性：回应当下的原生家庭焦虑
- 触动情绪：愤怒（不公）+ 悲伤（失望）+ 喜悦（独立）

### 案例3：《追妻火葬场》

**主流叙事**：爱情是纯洁的、浪漫的
**被掩盖的真相**：爱情中充满权力、控制、占有、背叛
**颠倒后的题材**：男主背叛女主，女主离开，男主后悔追妻

**为什么有价值**：
- 触及人性本质：爱情中的权力和控制
- 揭示被掩盖的真相：爱情不一定纯洁
- 普世性：全球共鸣（爱情背叛）
- 当下性：回应当下的情感焦虑
- 触动情绪：愤怒（背叛）+ 悲伤（失去）+ 喜悦（复仇）

## "开天眼"方法论

### 步骤1：剥离分别

**操作清单**：
- [ ] 剥离政治：不问"政治正确"，问"人性真实"
- [ ] 剥离文化：不问"文化传统"，问"普世共鸣"
- [ ] 剥离道德：不问"道德高尚"，问"情感真实"
- [ ] 剥离宗教：不问"信仰正确"，问"人性困境"
- [ ] 剥离传统：不问"传统美德"，问"真实欲望"

**示例**：
```
题材：母亲偏心

剥离前：
- 政治：家庭和谐是社会稳定的基础
- 文化：母爱是伟大的
- 道德：子女应该孝顺父母
- 传统：家和万事兴

剥离后：
- 人性真实：母亲也是人，也有偏心
- 普世共鸣：全球都有原生家庭创伤
- 情感真实：被偏心的孩子会愤怒、悲伤
- 人性困境：如何面对不公的原生家庭
```

### 步骤2：如实观照

**操作清单**：
- [ ] 观照政治：政治如何影响人的行为？
- [ ] 观照文化：文化如何塑造人的认知？
- [ ] 观照道德：道德如何约束人的欲望？
- [ ] 观照宗教：宗教如何安抚人的恐惧？
- [ ] 观照传统：传统如何限制人的选择？

**示例**：
```
观照对象：传统家庭伦理中的"孝道"

观照结果：
- 政治：孝道是维护家庭秩序的工具
- 文化：孝道是中国传统文化的核心
- 道德：孝道是子女的道德义务
- 传统：孝道是家族传承的基础

本质：孝道是父母控制子女的权力工具
```

### 步骤3：颠倒真相

**操作清单**：
- [ ] 找到主流叙事中被美化的部分
- [ ] 揭示被美化背后的丑陋
- [ ] 设计题材，把真相颠倒过来

**示例**：
```
主流叙事：母爱是伟大的
被美化的部分：母亲的牺牲、奉献、无私
背后的丑陋：母亲的控制、情感勒索、偏心
颠倒后的题材：母亲偏心弟弟，逼走女儿，女儿成功后母亲后悔

主流叙事：努力就能成功
被美化的部分：个人奋斗、拼搏、坚持
背后的丑陋：阶层固化、资源垄断、机会不平等
颠倒后的题材：底层人再努力也无法突破阶层，最后选择躺平或反抗
```

3. 问：这个冲突是否触动人性本质？
4. 问：这个冲突是否有当下性？

**示例**：
```
题材：母亲偏心弟弟

核心冲突：原生家庭的不公
普世性：✅ 全球都有原生家庭问题
人性本质：✅ 触及人性的不公和愤怒
当下性：✅ 回应当下的原生家庭焦虑

结论：这是一个有价值的题材
```

## Agent 应用指南

### episode-architect（分集规划师）

**应用场景**：
- 在分集规划时，使用"开天眼"方法论评估题材价值
- 确保每一集都触及人性本质，而不是停留在表面冲突
- 确保整体架构揭示"被颠倒的真相"

**操作方法**：
1. 读取原文，识别主流叙事
2. 使用"开天眼"方法论，找到被掩盖的真相
3. 设计分集架构，逐步揭示真相
4. 确保每一集都有情绪钩子，触动观众

### script-writer（剧本作家）

**应用场景**：
- 在写作时，从"好恶"出发设计冲突
- 不要从"应该"出发，要从"触动"出发
- 确保每一场戏都触及人性本质

**操作方法**：
1. 识别当场戏的核心冲突
2. 问：这个冲突是否触及人性本质？
3. 问：这个冲突是否触动观众的"好恶"？
4. 如果不够深刻，使用"颠倒真相"方法加深

### review-director（审核导演）

**应用场景**：
- 在审核时，评估题材是否有深度和新意
- 检查是否停留在表面冲突，还是触及人性本质
- 检查是否揭示"被颠倒的真相"

**审核清单**：
- [ ] 题材是否触及人性本质？
- [ ] 题材是否揭示被掩盖的真相？
- [ ] 题材是否有普世性和当下性？
- [ ] 题材是否触动全球众生的情绪？
- [ ] 冲突是否从"好恶"出发，而不是从"应该"出发？

## 警告与边界

### 警告1：不是为了颠覆而颠覆

**错误理解**：
- 为了"新意"而刻意颠覆主流叙事
- 为了"深度"而刻意挑战道德底线
- 为了"价值"而刻意制造争议

**正确理解**：
- 颠倒真相是为了揭示人性本质，不是为了颠覆而颠覆
- 挑战主流叙事是为了触动观众，不是为了制造争议
- 深度和新意是自然的结果，不是刻意的目标

### 警告2：不是无视合规

**重要提醒**：
- "开天眼"不等于无视合规红线
- 揭示真相不等于违反法律法规
- 触动人心不等于突破道德底线

**操作原则**：
- 在合规范围内，最大化题材深度
- 使用隐喻、象征、留白等手法，规避合规风险
- 参考 `05-compliance-boundaries.md` 确保合规

### 警告3：不是否定所有主流价值

**正确理解**：
- 不是否定所有主流价值，而是看清它们的本质
- 不是批判所有道德规范，而是理解它们如何运作
- 不是颠覆所有文化传统，而是揭示它们背后的人性

**操作原则**：
- 保持中立和客观，不带价值判断
- 揭示真相，但不强加观点
- 让观众自己思考和判断

### 流程图

```
用户提供原文
    ↓

    ↓

    ↓

    ↓

    ↓

    ↓

    ↓

    ↓

    ↓
review-director 审核题材深度
```

### 关键检查点

**novel-analyzer 阶段**：
- 识别原文中的主流叙事
- 识别原文中被掩盖的真相
- 评估原文的题材价值

**episode-architect 阶段**：
- 使用"开天眼"方法论设计分集架构

**script-writer 阶段**：
- 从"好恶"出发设计冲突
- 确保每一场戏都触及人性本质
- 使用"颠倒真相"方法加深冲突

**review-director 阶段**：
- 评估题材是否有深度和新意
- 检查是否触及人性本质
- 检查是否揭示"被颠倒的真相"

## 金句与核心概念

### 核心金句

1. **"众生没有真理、真相，只有好恶，所以你才有价值。"**
   - 含义：观众不关心真理，只关心情绪
   - 应用：从情绪出发设计题材，而不是从真理出发

2. **"觉悟天道，是名开天眼。"**
   - 含义：超越表象，看到本质
   - 应用：剥离政治、文化、道德、宗教、传统的束缚

3. **"把被文化、道德颠倒的真理、真相颠倒过来。"**
   - 含义：揭示被主流叙事掩盖的真相
   - 应用：找到被美化的丑陋，设计题材揭示真相

4. **"随便你怎么写怎么拍都是新意和深度，这就是钱，就是名利、成就、价值。"**
   - 含义：触及人性本质的题材，自然有深度和价值
   - 应用：不要刻意追求新意，而是追求人性本质

### 核心概念

- **开天眼**：剥离分别，如实观照，颠倒真相
- **众生好恶**：观众的情绪和偏好，而不是真理和真相
- **颠倒真相**：揭示被主流叙事掩盖的真相
- **全球众生视角**：从普世人性出发，找出当下触动人心的内容
- **人性本质**：欲望、恐惧、贪婪、爱恨，而不是道德、文化、传统

## 选题底层逻辑补充

### 短剧与小说的本质区别

短剧借鉴看小说，这样说对不对呢？目前来说是这样的，至少从数据上来看很成功，但是未来肯定会发生改变，因为小说和短剧从本质上来讲是两个东西，短剧属于一种视听方式。

小说的分类有很多，都市、神医、赘婿、离婚、霸道总裁爱上我等等，看上去和短剧的分类很像，但是短剧包含的元素要比小说多得多。一上来是一个赘婿，然后被退婚，结果他的身份是个龙王，然后他还是个神医，最后他还会鉴宝？这该怎么去分类选题材呢？所以我们必须要知道，该怎么分类，怎么选题，我们只能从底层逻辑上考虑该选择什么内容去写。

### 短剧的本质：故事+产品的结合物

短剧是什么？他是一个故事加产品结合的产物。

为什么是故事+产品？首先短剧不可否认，他再短，内容再没有营养，也是有着故事的。那么产品呢？他当然更是一个产品，因为他需要用户充值，而且是重付费。那么我们就从故事和产品本身具有的属性来剖析问题。

#### 用户购买这个产品的目的是什么？又有什么属性？

1. **解压**：他看着会很爽，无论是打脸还是扮猪吃老虎，都可以给观众提供充足的情绪价值。
2. **代入感**：都是发生在自己身边的事，与我们生活都息息相关。一个快递员，一个职场员工等等，都会让我们看到身边自己的影子，愿意代入故事里。
3. **粘性**：要知道一个短剧100集，所以必须要有一种粘性，可以让用户一直看下去。

那么从这三个角度去考虑，有的同学是不是就知道，自己的本子需要有什么东西了？

### 故事的四个组成元素

那从故事的角度去考虑呢？故事由四个元素组成：**世界观、人物、事件、主题**。

1. **世界观**：就是你的角色所在的世界是一个什么样的世界？修仙的？都市的？弱肉强食的还是人人平等的？在真实世界中，各种规则是共存的，但是在剧本里，往往只有一个世界观。
2. **人物**：你的角色是一个什么样的人物呢？职业，技能，背景，身份，性格等等。
3. **事件**：你的剧本讲了一个什么事。
4. **主题**：就是看了这个故事你得到了什么？你剧本要表达的中心思想是什么？

### 短剧主题的特殊性：解压是第一要义

新手最容易犯的错误：表达自己。我们要学会从观众的角度去考虑问题，观众想要看到的是什么，而不是我们想表达什么。那么观众看我们的剧想要看到的是什么？想要得到的是什么呢？就是解压，获得一种爽感。

在短剧中，和传统影视和小说的区别就在于第四点——**主题**。短剧的主题就是解压，就是爽感。为了达到这个目的，我们往往不能兼顾其他的元素，因为时间和篇幅都有限。都有但是不展开：世界观不展开，人物不展开。我们不会用大量的笔墨去描写世界观，甚至都不去写世界观；不去塑造他，短剧中的人物形象更是很简单，没有变化，没有成长等等。

对于事件这部分，我们第一个选题逻辑只有一个字——**爽**。为了纯粹的爽而服务，那么就不能写一些虐的、悲伤的、压抑的题材。当然为了爽而铺垫的侮辱，为了甜蜜的言情剧前面的拉扯，不属于提到的虐和压抑，那种情节设计属于起承转合的情绪曲线。

### 衡量故事精彩的三个元素

那衡量一个故事精不精彩，会涉及到三个元素：**对抗、变化、共情**。

我们在看一个电影或者电视剧，其中必然会有对抗。有阻挠主角的反派，他们就会形成对抗，然后主角会被打败，再次反击，被打败再反击最后成功，会有变化，最后我们会被这个故事感动，得到共情。

那么怎么才算精彩呢？

- **对抗足够强烈**：冲击足够强烈，这是为什么很多短剧开局会有一场打戏，因为他足够吸引眼球，场面够大，对抗足够激烈。
- **变化**：如果进入这个行业，投过稿的同学，应该经常会听到编辑说要求多些反转，多些创新，多些意想不到的变化。这会让观众期待事情的发展，让他既有一个模糊的猜测，又不能完全猜得对，所以他们会去验证自己的猜想看下去。
- **共情**：共情有很多种，首先共情的定义是人类共同的情感。我们在看剧时，主角被欺负、被侮辱，就会有气愤的感觉；被误解，我们就会有一种委屈的情感等等。一个好的剧本是一定要能带动观众情绪的。

那么这个时候就会发现，所谓的共情，是不是就是代入感呢？**共情就是代入**。

### 最终结论

在这三个元素里，决定一个短剧的剧本好不好，最重要的就是**共情**。

所以我们做一个短剧，要选题，**解压**和**代入**是我们首先考虑的问题。

### 爽感的心理学层级

在心理学里，人的爽感分为三个层级：

#### 第一层级：性与征服

这是动物层级的爽点，为了繁殖就需要竞争打败对手，这很容易理解。即使是人类，我们这一生最基本的需求是什么？成家立业，再直接一点，就是钱和女人/男人。动物会通过暴力征服得到交配权，而人类也会通过施展财力，在感情中获取优势。

这第一层级的爽点是最原始的，最低级最初级的，但同时也是劲最大的，也是现实中人们YY最多的。

为什么我们会觉得短剧很俗呢？因为他充斥着最低级的需求，最低级的爽点。钱俗吗？很俗。不是我清高我了不起，而是因为钱它换来的东西，永远都是不值钱的——不知道能不能理解。钱换不来理想，换不来爱情，换不来崇高的东西。性它俗吗？也俗。这就是人们的共同认知，但是你说他俗，你想要吗？我想没人不想。这也就能解释为什么俗里俗气的剧情那么多人会去喜欢了。

哪些剧里没有这些爽点？是的，所有的剧里都会包含它们，无论是爱情还是离婚，无论是有钱还是能打，都涵盖在内。

#### 第二层级：优势、归属、秩序

**1. 优势**

优势是什么呢？简单来说，**我比你强就叫优势，我有你没有的东西也叫优势**。我们为什么会代入主角呢？因为主角有优势，主角与众不同，主角独一无二，主角有钱，有地位，有实力。围绕着优势这一点又有多少题材可写呢？想必大家现在心里已经有一部分答案了。

**2. 归属**

至于归属是什么意思，可以理解为民族精神、民族感情。为什么这样会产生爽感呢？举个例子，奥运会中国得到了金牌，爽吧。那运用在短剧上怎么处理呢？

归属是一个集体性质的东西。如果我们没有优势，甚至打不过别人怎么办？有句话叫做"打不过就加入"。如何利用归属创造爽感呢？比如办公室类型的例子，一些底层职业推翻上级；再比如说性别也是一个集体，小仙女痛撕渣男等等，也会产生共鸣和爽点。这个就要看具体怎么安排剧情了。

**3. 秩序**

秩序为什么会爽呢？修路蹄子、洗脏地毯、房屋改造，是不是都很解压都很爽？所谓的秩序就是**从混乱变为有序状态**。比如主角的生活一团糟，被妻子绿，被朋友背叛，那主角通过一系列行为，最后达成复仇，也是一种不错的爽点。

但是可以看得出来，以上说的五种爽点，他的层级是递减的。也就是说，前三种爽点（性与征服）是最为简单粗暴也最为明显的，后面两者（归属、秩序）需要进行一番设计才能够达到效果。

#### 第三层级

至于第三层级的爽点，就不去阐述了，短剧是用不到的。

### 爽点的叠加与选题应用

以上提到的爽点，是可以共存的。**一个好的剧本包含的爽点维度越多越好。**

赘婿离婚结果是个战神，战神还是个神医，神医还会鉴宝——一个道理。这一系列体现着什么？

- **赘婿、离婚**：后面都会安排一个真女主，这是**两性**（第一层级）
- **战神也好、龙王也好**：会打架、有钱，这属于**征服**（第一层级）
- **优势**：地位、医术等等（第二层级）

就不展开叙述了。

**综上所述，大家在选题的时候，就要考虑到这些内容怎么安排，选择哪个题材可以更多的融入这些元素。**

### 共鸣的核心：爽点 ≠ 共鸣

有人会问，这不是一回事吗？其实不然，爽点是爽点，共鸣是共鸣。你觉得爽的，或许观众不会觉得爽。之前提到过人类共通的爽点，那为什么会觉得不爽呢？这个问题在于：**我们的爽点，有没有落实到日常生活的困境当中——也就是有没有产生共鸣。**

只要是人，不管有钱有势还是没钱没势的，多多少少都会有些困境。但我们不可否认的是，那些有钱有势的人，可能对于YY的需求不会特别高。他们的困境可能不是靠YY来共鸣的——一来他们比较忙，没有这个时间；二来，在我们的创作中，可能他们的世界本就是这样如此了。

所以我们的观众就产生了，我们付费主力就产生了：**有些闲钱可以充值，而又有着普通人困境和烦恼的人们。**

#### 分类的真相：不同爽点对应不同人群的困境

那么我们就知道那么多的分类是怎么分出来的了——这些分类都在满足什么需求、产生什么共鸣。

**1. 两性爽点**
- **类型**：离婚文、赘婿文、三个哥哥把我宠上天、霸道总裁等
- **共鸣人群**：感情不如意的、在婆家被看不起的、缺少关爱的……等等被情感包围的烦恼

**2. 征服爽点**
- **类型**：龙王、战神等
- **共鸣人群**：男性——因为征服是男性永远的主题，永远是能得到YY满足的

优势、归属、秩序都是如此，就不一一举例子了。

这里要单独强调一下：看上去似乎是一些废话，但是我们仔细想想——我们接触到的世界是什么？我们接触不到我们笔下主角的世界，这是肯定的。那么我们更不会知道那个层级的人的烦恼、他们的需求。所以**我们稳稳地抓住能带给我们收益的目标人群就足够了**。说白了，我们是服务行业，服务于充值付费者。

#### 共鸣的核心：让观众尽快代入主角

那么这和共鸣有什么关系呢？

我们可以想到生活中去类比：一个人出了事，发生了危险，是一个陌生人更会让你揪心，还是身边的人？

**这就是共鸣**。我们要通过足够的戏份，让我们的角色塑造起来，让观众熟悉，尽快代入进去。

**例如**：如果10集卡点要做的是言情戏，那么你前十集的任务就是拉扯情绪——拉扯男女主之间的恩怨纠葛，拉扯你们之间的羁绊，而不是拿出几个无关痛痒的配角发生事件、误会等等。

#### 性别差异：男女共鸣的逻辑不同

要做到共鸣，我们需要清楚一件事情：**性别区别，男女是不一样的**。

这里特指在短剧中：

- **男性视角**：一般是通过自己的力量去征服（以征服类为例）
- **女性视角**：一般是靠他人的力量去征服（霸总、哥哥宠我上天等，一般情况下都是外界力量给女主撑腰保护）

（这里先叠个甲保个命：我的意思从来不是男女不平等或者男性强于女性，我们只是在针对短剧去聊，从市场的角度来看，从创作的角度来看。）

**女频的共鸣是什么？** 被保护，被疼爱，被宠。

但是你说有谁强谁弱吗？其实没有的。无论男频还是女频，**他们的爽都来自于不劳而获，天降横财**。

所以我这里要提出一下关于性别之间的差异化。大家在构思剧本的时候，尤其是女孩子，不要被我的例子思路带偏，**你要看到的是他的本质，底层逻辑**。我们要学会从最底层挖掘观众的需求，这是一个优秀的编剧一定要做到的事情。

#### 总结

**第一**：共鸣要与爽感建立联系，你得需要找到观众生活息息相关的需求。

**第二**：找到以后，要让观众尽快去熟悉主角，代入主角，通过事件不断去刺激观众。
