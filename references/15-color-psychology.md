# 色彩心理学

## 核心原则

**第一性原则**：色彩不仅是视觉元素，更是情绪语言和叙事工具。

**目标**：通过科学的色彩心理学原理，设计视觉情绪，增强叙事表达，创造视觉冲击。

---

## 一、色彩情绪映射表

|-----|-----------|---------|---------|

| 低明度 | 沉重、压抑、封闭 | 降低情绪、增加压迫感 |

## 二、色彩叙事原则

### 2.1 色彩对比叙事

#### 原则1：冷暖对比
- **定义**：使用冷色和暖色的对比，表现情绪或关系的对立
- **应用**：
  - 主角（暖色调）vs 反派（冷色调）
  - 过去（暖色调）vs 现在（冷色调）
  - 希望（暖色调）vs 绝望（冷色调）

**示例**：
```
场景1：回忆（暖色调）
※ 画面呈现温暖的橙黄色调
△ 她和他在夕阳下牵手，笑容灿烂

场景2：现实（冷色调）
※ 画面呈现冰冷的蓝灰色调
△ 她独自站在雨中，眼神空洞
```

#### 原则2：饱和度对比
- **定义**：使用高饱和度和低饱和度的对比，表现情绪强度的变化
- **应用**：
  - 情绪高涨（高饱和度）vs 情绪低落（低饱和度）
  - 重要场景（高饱和度）vs 过渡场景（低饱和度）
  - 主角视角（高饱和度）vs 配角视角（低饱和度）

**示例**：
```
场景1：情绪高涨（高饱和度）
※ 画面色彩鲜艳，红色、金色强烈
△ 她站在舞台中央，接受掌声，眼神坚定

场景2：情绪低落（低饱和度）
※ 画面色彩黯淡，灰色、褐色主导
△ 她坐在角落，低着头，无人问津
```

#### 原则3：明暗对比
- **定义**：使用明暗对比，表现善恶、真相与谎言、希望与绝望
- **应用**：
  - 善（明亮）vs 恶（黑暗）
  - 真相（明亮）vs 谎言（黑暗）
  - 希望（明亮）vs 绝望（黑暗）

**示例**：
```
场景1：真相揭晓（明亮）
※ 画面突然变亮，阳光透过窗户照进来
△ 她看着证据，眼神清明："原来如此。"

场景2：谎言揭穿（黑暗）
※ 画面突然变暗，阴影笼罩他的脸
△ 他低下头，不敢直视她的眼睛
```

### 2.2 色彩渐变叙事

#### 原则1：情绪渐变
- **定义**：通过色彩的渐变，表现情绪的变化过程
- **应用**：
  - 从希望到绝望：暖色 → 冷色
  - 从平静到愤怒：蓝色 → 红色
  - 从迷茫到清醒：灰色 → 明亮色

**示例**：
```
第1集：希望（暖橙色调）
※ 她满怀期待地走进公司

第5集：动摇（黄绿色调）
※ 她开始怀疑自己的选择

第10集：绝望（冷蓝色调）
※ 她站在天台边缘，眼神空洞

第15集：重生（明亮白色调）
※ 她重新站起来，眼神坚定
```

#### 原则2：时间渐变
- **定义**：通过色彩的渐变，表现时间的流逝
- **应用**：
  - 一天的时间：清晨（蓝色）→ 正午（黄色）→ 黄昏（橙色）→ 夜晚（深蓝/黑色）
  - 季节变化：春（绿色）→ 夏（黄色）→ 秋（橙色）→ 冬（白色/灰色）

#### 原则3：关系渐变
- **定义**：通过色彩的渐变，表现人物关系的变化
- **应用**：
  - 从陌生到亲密：冷色 → 暖色
  - 从亲密到疏离：暖色 → 冷色
  - 从对立到和解：对比色 → 相近色

## 三、类型化色彩方案

### 3.1 复仇/逆袭类（男频）

**主色调**：冷色调（蓝、灰、黑）+ 红色点缀

**色彩策略**：
- **前期（压抑期）**：低饱和度的蓝灰色调，表现压抑和屈辱
- **中期（觉醒期）**：逐渐加入红色元素，表现愤怒和力量觉醒
- **后期（复仇期）**：高饱和度的红黑色调，表现力量和复仇

**具体应用**：
```
第1-3集（压抑期）：
- 主色调：低饱和度蓝灰色
- 主角服装：灰色、深蓝色
- 环境：昏暗、压抑

第4-10集（觉醒期）：
- 主色调：蓝灰色 + 红色点缀
- 主角服装：开始出现红色元素（领带、配饰）
- 环境：逐渐明亮，红色光线增加

第11-20集（复仇期）：
- 主色调：高饱和度红黑色
- 主角服装：黑色西装 + 红色衬衫/领带
- 环境：强烈对比，红色主导
```

### 3.2 甜宠/虐恋类（女频）

**主色调**：暖色调（粉、橙、金）+ 蓝色对比

**色彩策略**：
- **甜宠场景**：高饱和度暖色调（粉色、橙色、金色）
- **虐恋场景**：低饱和度冷色调（蓝色、灰色）
- **情绪反转**：从暖色突然转为冷色，或从冷色突然转为暖色

**具体应用**：
```
甜宠场景：
- 主色调：粉橙色调
- 女主服装：粉色、白色、浅色系
- 男主服装：米色、浅灰色、暖色系
- 环境：柔和光线、温暖氛围

虐恋场景：
- 主色调：冷蓝灰色调
- 女主服装：深色、冷色系
- 男主服装：黑色、深蓝色
- 环境：昏暗光线、压抑氛围

情绪反转：
※ 画面从温暖的粉橙色调突然转为冰冷的蓝灰色调
△ 她的笑容僵住，眼神黯淡下来
```

### 3.3 玄幻/古装类

**主色调**：紫色、金色、青色 + 黑色对比

**色彩策略**：
- **仙侠/正派**：青色、白色、金色（清冷、高贵）
- **魔道/反派**：紫色、红色、黑色（神秘、邪恶）
- **凡间/日常**：低饱和度暖色调（接地气）

**具体应用**：
```
仙侠场景：
- 主色调：青白金色调
- 主角服装：白色、青色、金色点缀
- 环境：云雾缭绕、仙气飘飘

魔道场景：
- 主色调：紫红黑色调
- 反派服装：黑色、紫色、红色点缀
- 环境：暗黑、压抑、神秘

凡间场景：
- 主色调：低饱和度暖色调
- 服装：褐色、米色、灰色
- 环境：市井、烟火气
```

### 3.4 现代都市/职场类

**主色调**：中性色（灰、黑、白）+ 彩色点缀

**色彩策略**：
- **职场场景**：低饱和度中性色（专业、冷静）
- **情感场景**：高饱和度暖色调（温暖、亲密）
- **冲突场景**：高对比度冷色调（紧张、对立）

**具体应用**：
```
职场场景：
- 主色调：灰白黑色调
- 服装：黑色西装、白色衬衫、灰色套装
- 环境：现代办公室、玻璃幕墙

情感场景：
- 主色调：暖橙色调
- 服装：休闲装、暖色系
- 环境：咖啡厅、家、温馨空间

冲突场景：
- 主色调：冷蓝灰色调
- 服装：深色、冷色系
- 环境：会议室、对峙空间
```

## 四、色彩与情绪段落

### 4.1 情绪建立（0-3秒）

**色彩策略**：使用环境色彩快速建立情绪基调

| 情绪类型 | 色彩方案 | 示例 |
|---------|---------|------|
| 平静 | 低饱和度蓝绿色 | 清晨的办公室，柔和的蓝绿色光线 |
| 紧张 | 高对比度冷色调 | 昏暗的走廊，冷白色灯光 |
| 温馨 | 暖橙色调 | 家中的客厅，温暖的橙黄色灯光 |
| 压抑 | 低饱和度灰色调 | 阴雨天的街道，灰蒙蒙的色调 |

### 4.2 情绪拉扯（3-8秒）

**色彩策略**：使用色彩对比表现情绪冲突

| 冲突类型 | 色彩对比 | 示例 |
|---------|---------|------|
| 内心矛盾 | 冷暖对比 | 她的脸一半在暖光中，一半在冷光中 |
| 人物对立 | 互补色对比 | 他（蓝色调）vs 她（橙色调） |
| 真相与谎言 | 明暗对比 | 明亮的真相 vs 黑暗的谎言 |

### 4.3 情绪爆点（8-12秒）

**色彩策略**：使用高饱和度色彩或强烈对比表现情绪高潮

| 情绪类型 | 色彩方案 | 示例 |
|---------|---------|------|
| 愤怒爆发 | 高饱和度红色 | 画面突然充满红色，他猛地站起身 |
| 悲伤崩溃 | 低饱和度蓝色 | 画面变得灰蓝，她靠墙滑坐到地上 |
| 惊喜反转 | 明亮金色 | 画面突然变亮，金色光芒洒下 |
| 恐惧惊恐 | 高对比黑白 | 画面失去色彩，只剩黑白对比 |

### 4.3 情绪反转/悬念（12-15秒）

**色彩策略**：使用色彩突变表现情绪反转

| 反转类型 | 色彩变化 | 示例 |
|---------|---------|------|
| 从希望到绝望 | 暖色 → 冷色 | 温暖的橙色突然转为冰冷的蓝色 |
| 从平静到危险 | 中性色 → 红色 | 灰色调突然被红色警示灯打破 |
| 从真实到虚幻 | 正常色 → 异常色 | 正常色调突然变为诡异的紫绿色 |

## 五、色彩与人物设计

### 5.1 主角色彩设计

**原则**：主角的色彩应该随着人物弧光变化

| 人物阶段 | 色彩方案 | 心理状态 |
|---------|---------|---------|
| 初始状态 | 低饱和度、中性色 | 平凡、迷茫、压抑 |
| 觉醒阶段 | 逐渐加入彩色元素 | 成长、觉醒、力量增强 |
| 巅峰状态 | 高饱和度、标志性色彩 | 强大、自信、完整 |

**示例：复仇男主**
```
第1-3集（压抑期）：
- 服装：灰色T恤、深蓝色牛仔裤
- 色彩：低饱和度冷色调
- 心理：屈辱、压抑、隐忍

第4-10集（觉醒期）：
- 服装：开始出现红色元素（红色领带、红色配饰）
- 色彩：蓝灰色 + 红色点缀
- 心理：愤怒、觉醒、力量增强

第11-20集（复仇期）：
- 服装：黑色西装 + 红色衬衫/领带
- 色彩：高饱和度红黑色调
- 心理：强大、冷酷、复仇
```

### 5.2 反派色彩设计

**原则**：反派的色彩应该与主角形成对比

| 主角色彩 | 反派色彩 | 对比效果 |
|---------|---------|---------|
| 暖色调 | 冷色调 | 温暖 vs 冷酷 |
| 明亮色 | 暗黑色 | 光明 vs 黑暗 |
| 纯色 | 混浊色 | 纯洁 vs 邪恶 |

**示例：甜宠剧**
```
女主（暖色调）：
- 服装：粉色、白色、浅色系
- 色彩：温暖、柔和、明亮
- 性格：善良、温柔、纯真

女配/反派（冷色调）：
- 服装：深色、冷色系、黑色
- 色彩：冷酷、压抑、暗黑
- 性格：心机、冷酷、邪恶
```

### 5.3 配角色彩设计

**原则**：配角的色彩应该低于主角的饱和度，避免抢戏

| 角色类型 | 色彩方案 | 设计原则 |
|---------|---------|---------|
| 主角 | 高饱和度、标志性色彩 | 视觉焦点 |
| 重要配角 | 中饱和度、辅助色彩 | 支持主角，不抢戏 |
| 次要配角 | 低饱和度、中性色彩 | 背景化，不干扰 |

## 六、色彩与场景设计

### 6.1 场景色彩基调

| 场景类型 | 色彩基调 | 情绪效果 | 适用剧情 |
|---------|---------|---------|---------|
| 家/温馨空间 | 暖橙色调 | 温暖、安全、放松 | 情感戏、日常戏 |
| 办公室/职场 | 冷灰色调 | 专业、冷静、压抑 | 职场戏、冲突戏 |
| 医院 | 冷白色调 | 冷漠、紧张、无助 | 生死戏、转折戏 |
| 酒吧/夜店 | 暗红紫色调 | 暧昧、危险、放纵 | 情感戏、冲突戏 |
| 户外/自然 | 绿色调 | 平静、治愈、希望 | 治愈戏、转折戏 |
| 豪宅/权力空间 | 金黑色调 | 奢华、权力、压迫 | 权力戏、对峙戏 |

### 6.2 场景色彩对比

**原则**：通过场景色彩对比，表现情绪或剧情的转折

**示例1：从温馨到冷酷**
```
场景1：家中（暖橙色调）
※ 她和他在温暖的客厅里，笑容灿烂
△ 橙黄色的灯光，温馨的氛围

场景2：办公室（冷灰色调）
※ 她面对冷酷的老板，眼神坚定
△ 冷白色的灯光，压抑的氛围

**对比效果**：从温暖到冷酷，表现她从家庭到职场的转变
```

**示例2：从压抑到释放**
```
场景1：密闭空间（低饱和度灰色调）
※ 她被困在狭小的房间里，眼神绝望
△ 昏暗的灯光，压抑的氛围

场景2：户外（高饱和度绿色调）
※ 她冲出房间，站在阳光下，深呼吸
△ 明亮的阳光，绿色的草地，释放的氛围

**对比效果**：从压抑到释放，表现她从困境到自由的转变
```

## 七、色彩与镜头语言

### 7.1 色彩与景别

| 景别 | 色彩策略 | 效果 |
|-----|---------|------|
| 特写 | 简化色彩，突出主体 | 聚焦情绪，减少干扰 |
| 中景 | 平衡色彩，主体与环境 | 展现关系，增加层次 |
| 全景 | 丰富色彩，展现环境 | 建立氛围，增加信息 |

### 7.2 色彩与运镜

| 运镜方式 | 色彩变化 | 效果 |
|---------|---------|------|
| 推镜头 | 从复杂色彩到简化色彩 | 聚焦情绪，增强代入感 |
| 拉镜头 | 从简化色彩到复杂色彩 | 展现环境，增加信息 |
| 摇镜头 | 色彩对比或渐变 | 展现关系或情绪变化 |
| 跟镜头 | 保持色彩一致性 | 保持情绪连贯性 |

## 八、实战应用

### 8.1 色彩设计流程

**步骤1：确定类型和情绪基调**
- 这是什么类型的故事？（复仇/甜宠/玄幻/职场）
- 整体情绪基调是什么？（压抑/温暖/神秘/冷酷）

**步骤2：设计主色调**
- 主色调是什么？（冷色/暖色/中性色）
- 饱和度如何？（高/中/低）
- 明度如何？（明亮/中等/昏暗）

**步骤3：设计色彩对比**
- 使用哪种对比？（冷暖/饱和度/明暗）
- 对比的目的是什么？（表现对立/情绪变化/剧情转折）

**步骤4：设计色彩渐变**
- 色彩如何随剧情变化？（从暖到冷/从暗到明）
- 色彩如何随人物成长变化？（从灰到彩/从冷到暖）

**步骤5：设计人物色彩**
- 主角的标志性色彩是什么？
- 反派的对比色彩是什么？
- 配角的辅助色彩是什么？

**步骤6：设计场景色彩**
- 每个场景的色彩基调是什么？
