# 合规边界

## 适用范围

适用于国内短剧平台（抖音、快手、优酷、爱奇艺、小程序剧等）的内容合规要求。出海平台另有标准，本文件以国内合规为主。

合规检测在两个时机执行：
1. **分析阶段**：扫描原著，标记高风险内容，在分析报告中列出
2. **写集后自检**：每集完成后，作为自检的最后一道关卡

---

## 审核对象

1. 题材选择
2. 台词内容
3. 画面描述
4. 角色设定
5. 视觉内容（分镜/视频）

---

## 一、红线内容（必须删除或彻底改写）

以下内容出现在剧本中会导致平台拒审，必须在改编阶段直接处理，不保留：

### 选书禁区清单

**题材禁区：**
- 后宫类（多女主、三妻四妾）
- 同人类（基于他人作品的二次创作）
- 都市龙王（都市隐藏身份+极端碾压）
- 特种兵类（涉及军事敏感）
- 盗墓类（封建迷信+违法行为）
- 神医下山（封建迷信+医疗违规）
- 都市高手（过度暴力倾向）
- 商斗类（涉及现实商业敏感）
- 黑道类（涉及违法犯罪）
- 群像类（九个师父、七个姐姐等，角色过多难以聚焦）

**内容禁区：**
- 黄暴血腥（详细的性描写、暴力伤害描写）
- 涉政内容（现实政治人物、党政机构负面描写）
- 封建迷信（算命、风水、鬼神等作为核心设定）
- 女频虐恋（过度虐待女主的情节）

**选书原则：**
- 优先选择：剧情简单粗暴、金手指有趣、快节奏、脑洞大、搞笑玩梗、开局噱头足的书
- 避免选择：日常文（冲突太小）、过于黑暗的剧情、涉及上述禁区的任何元素

### 暴力类

- 详细的肢体伤害描写（骨折、出血、器官描写）
- 未成年人参与的暴力场景
- 以虐待为主要卖点的情节
- **处理方式**：战斗结果保留，过程省略或改为「闻声不见人」的画外音处理

### 人物设定类

- 任何角色明确描述为未成年的恋爱或亲密关系
- **处理方式**：直接将角色设定改为成年人，无需说明

### 政治敏感类

- 涉及现实政治人物、党政机构的负面描写
- 涉及历史敏感事件的不当解读
- **处理方式**：架空处理，将现实机构改为虚构机构名称

### 封建糟粕类

- 以正面视角呈现的「三妻四妾」关系（古代剧若有，需确保有价值观纠偏）
- 强迫性质的情感关系被美化
- **处理方式**：改写关系性质，或加入角色明确的负面反应

## 二、黄线内容（需要改写或降级处理）

以下内容不是绝对禁止，但需要控制程度或改写方式：

### 暴力程度

| 原著描写 | 改编处理 |
|---------|---------|
| 详细打斗过程（多段落） | 保留关键动作，压缩至2-3个 △ 描写 |
| 血腥结果描写 | 改为对手反应（倒地、脸色大变）替代直接描写 |
| 连续击打的快感描写 | 保留第一击和最后结果，中间用「一招制敌」处理 |

### 情感关系

| 原著描写 | 改编处理 |
|---------|---------|
| 露骨的亲密描写 | 用「♪ 音乐渐强，画面转黑」或镜头切走处理 |
| 婚外情被正面美化 | 确保有道德代价或角色反思，不能纯正面呈现 |
| 劈腿情节 | 可保留但需有明确的情感代价 |

### 赌博/金融

| 原著描写 | 改编处理 |
|---------|---------|
| 详细赌博场景 | 可保留结果（赢/输），删除赌博过程细节 |
| 炒股/投机细节 | 可提及，不展示具体操作手法 |

## 三、视觉内容合规（分镜/视频）

### 画面禁区

**绝对禁止：**
- 血腥暴力画面（流血、断肢、内脏）
- 色情低俗画面（裸露、性暗示动作）
- 恐怖惊悚画面（尸体、鬼怪、极端恐怖元素）
- 违法犯罪画面（吸毒、赌博细节、暴力犯罪过程）

**需要降级处理：**
- 打斗场景：只展示动作起手和结果，不展示击打过程
- 亲密场景：用镜头切换、画面转黑、音乐渐强处理
- 危险场景：不展示具体危险动作，用反应镜头替代

### 镜头语言合规

**安全镜头：**
- 特写：面部表情、眼神、手部动作
- 中景：人物对话、日常互动
- 远景：环境展示、场景转换

**风险镜头（需谨慎）：**
- 低角度仰拍：避免性暗示
- 特写身体部位：避免敏感部位
- 慢动作：避免暴力美学化

### 特效合规

**安全特效：**
- 光效：闪光、光晕、光束
- 粒子：火花、烟雾、魔法效果
- 文字：屏幕文字、字幕、标注

**风险特效（需谨慎）：**
- 血液特效：禁止
- 爆炸特效：可用，但不能过于血腥
- 变形特效：避免恐怖元素

## 四、分析阶段的合规扫描

在 `/分析` 阶段，对原著进行合规预扫描，在分析报告中加入合规章节：

```markdown
## 合规风险预扫描

### 红线风险（必须处理）
- [ ] 第X章：[风险内容描述] → 建议处理方式：[具体方案]

### 黄线风险（建议处理）
- [ ] 第X章：[风险内容描述] → 建议处理方式：[具体方案]

### 视觉内容风险
- [ ] 第X章：[画面风险描述] → 建议处理方式：[具体方案]

### 合规建议
[整体合规风险评级：低/中/高，以及总体改编建议]
```

**风险评级标准：**
- **低风险**：无红线，黄线少于3处，正常改编即可
- **中风险**：有1-2处红线或多处黄线，改编时需专门处理
- **高风险**：红线内容是核心情节（如主线是血腥复仇），需要大幅改写故事架构

## 五、写集后的合规自检项

在自检流程末尾，追加合规检查环节：

### 自动标记（AI自行判断并处理）

- 台词中出现的具体暴力伤害描写 → 改为结果描写
- △ 描写中超过3行的打斗细节 → 压缩
- 明显的未成年人亲密设定 → 自动改为成年人设定并告知用户
- 画面描述中的血腥暴力元素 → 改为反应镜头

### 提示用户确认

- 本集是否涉及赌博场景（建议删除过程细节）
- 本集是否有情感关系处理（确认是否需要降级处理）
- 本集是否有涉及现实政治机构的台词（建议架空处理）
- 本集是否有敏感画面描述（建议调整镜头语言）

## 六、出海模式的合规差异

当用户选择出海模式（英文剧本）时，合规标准不同：

| 维度 | 国内标准 | 出海标准（欧美） |
|------|---------|--------------|
| 暴力程度 | 严格限制 | 相对宽松，但不能过于血腥 |
| 情感关系 | 保守，需要道德代价 | 相对开放，多元关系可正面呈现 |
| 政治内容 | 高度敏感 | 相对宽松，但避免现实政治人物 |
| 宗教内容 | 较宽松 | 需谨慎，避免对特定宗教的负面描写 |
| 视觉内容 | 严格限制 | 相对宽松，但需符合分级制度 |

出海模式时，在合规扫描中切换为出海标准，并在报告中注明。

## 七、借鉴与抄袭边界

### 核心原则

**同质化会被拒稿，抄袭直接完蛋。微创新一下，既规避风险，又能杀出重围。**

### 可以借鉴的内容

| 可借鉴内容 | 说明 | 示例 |
|-----------|------|------|
| 题材类型 | 穿越、重生、系统流等大类 | 可以继续写穿越成蛇 |
| 爽点逻辑 | 打脸、逆袭、身份揭露等套路 | 可以用”被羞辱→身份揭露→打脸”的结构 |
| 升级框架 | 等级体系、升级路径 | 可以借用”筑基→金丹→元婴”的框架 |
| 情节模式 | 三幕式结构、情绪曲线 | 可以用”压抑→爆发→反转”的节奏 |

### 必须原创的内容

| 必须原创内容 | 说明 | 示例 |
|-------------|------|------|
| 具体剧情 | 每一集的具体情节 | 不能照搬原著的具体对话和场景 |
| 角色设定 | 角色的具体身份、关系、经历 | 不能完全复制原著角色 |
| 台词对白 | 所有台词必须重写 | 不能直接使用原著台词 |
| 场景设计 | 具体场景的布置和细节 | 不能照搬原著场景描写 |
| 视觉设计 | 分镜构图、镜头语言 | 不能照搬原著或其他作品的视觉风格 |

### 微创新规避抄袭的方法

以玄幻小蛇为例：

**方法一：换金手指**
```
原著：穿越成蛇，吞噬进化
借鉴：穿越成蛇，蜕皮升级（换金手指类型）
```

**方法二：换主角**
```
原著：穿越成蛇
借鉴：穿越成猫/狗/老虎（换动物种类）
```

**方法三：换世界观**
```
原著：现代都市穿越成蛇
借鉴：末世废土穿越成蛇（换世界观背景）
```

**方法四：换势力关系**
```
原著：蛇族vs人族
借鉴：蛇族vs龙族（换对立势力）
```

### 抄袭判定标准

| 抄袭类型 | 判定标准 | 后果 |
|---------|---------|------|
| 情节抄袭 | 连续3个以上情节点完全相同 | 拒稿，可能被起诉 |
| 台词抄袭 | 大段台词与原著一致 | 拒稿 |
| 角色抄袭 | 角色设定、关系、经历高度相似 | 拒稿 |
| 场景抄袭 | 场景描写与原著高度相似 | 拒稿 |
| 视觉抄袭 | 分镜构图、镜头语言与其他作品高度相似 | 拒稿 |

### 自查方法

写完每集后，进行抄袭自查：

1. **情节对比**：将本集情节与原著对应章节对比，是否有连续3个以上情节点完全相同？
2. **台词对比**：是否有大段台词与原著一致？
3. **角色对比**：角色设定是否与原著高度相似？
4. **场景对比**：场景描写是否与原著高度相似？
5. **视觉对比**：分镜构图是否与其他作品高度相似？

**判断标准：** 如果以上任何一项答案是”是”，必须立即修改。

## 八、业务常见禁区（短剧场景）

1. 后宫/都市龙王等高风险表达
2. 过度血腥、猎奇惩罚、侮辱性内容
3. 容易触发平台审核的”硬擦边”
4. 未授权知名IP强绑定
5. 视觉内容中的敏感元素（血液、裸露、恐怖）

审核时必须执行的检查命令：

## 十、输出规范

### PASS 输出

```
✅ 合规审核：PASS

**审核范围：** 第 X 集

**通过依据：**
1. 无红线内容
2. 黄线内容已降级处理
3. 视觉内容符合平台要求
4. 无抄袭风险

**风险评级：** 低风险
```

### FAIL 输出

```
❌ 合规审核：FAIL

**审核范围：** 第 X 集

**风险点清单：**

【红线风险】
1. **位置：** 第 2 场景，台词
   **问题：** 涉及详细暴力伤害描写
   **修改动作：** 改为结果描写，删除过程细节

【黄线风险】
1. **位置：** 第 3 场景，画面描述
   **问题：** 亲密场景描写过于露骨
   **修改动作：** 用镜头切换处理，添加【画面转黑】标记

【视觉内容风险】
1. **位置：** 第 1 场景，分镜描述
   **问题：** 血腥画面描述
   **修改动作：** 改为反应镜头，不展示血液

**风险评级：** 中风险
**建议：** 立即修改红线内容，黄线内容建议降级处理
```

## 十一、合规改编的正确姿势

**步骤一：提炼骨架**
- 只保留主线剧情
- 提取爽点逻辑
- 记录关键转折点

**步骤二：重新设计**
- 重新设计具体情节
- 重新设计角色关系
- 重新设计场景细节
- 重新设计视觉呈现

**步骤三：全部重写**
- 所有台词重写
- 所有场景描写重写
- 所有动作描写重写
- 所有分镜构图重新设计

**核心原则：** 借鉴框架，原创内容。

## 十二、2026年合规新规要点

> 来源：017-审稿自查表、028-行业风口+国家标准（2026-03-12 收编）

### 分类分层审核标准（2026年1月1日起施行）

| 类别 | 投资门槛 | 审核要求 |
|------|---------|---------|
| 重点微短剧 | ≥300万元 | 广电总局审核，需完整备案 |
| 普通微短剧 | 100-300万元 | 省级广电审核 |
| 其他微短剧 | <100万元 | 平台自审+报备 |

### 2026年新增红线

- 拜金主义、极端利己、不劳而获
- 出轨合理化、畸形婚恋（强制爱、替身文学、无底线复仇）
- 暴力复仇正当化（私刑无罪）
- 敏感职业误导（刑侦无证据定罪、医疗专业错误）
- 标题/封面低俗、哗众取宠、恶意恶搞

### AI短剧专项治理

- AI创作内容必须强制标注创作信息
- 未备案AI短剧一律下架
- 严禁AI魔改经典题材
- 规避版权纠纷与内容同质化风险

### 儿童短剧专项红线

- 禁止早恋、校园霸凌美化
- 禁止大尺度惊悚/暴力内容
- 涉及未成年人内容需额外审核

### 编辑+广电双审自查清单

**商业过审（编辑初审）**：
- [ ] 标题/简介3秒内看清题材、人设、核心爽点
- [ ] 前30秒立刻出冲突/危机/反转
- [ ] 每集高频冲突，无废话注水
- [ ] 人设目标明确、性格鲜明
- [ ] 每集结尾必有钩子
- [ ] 台词短句、口语化、有冲击力
- [ ] 场景少、成本可控

**广电合规（底线审核）**：
- [ ] 价值观正向，不宣扬负能量
- [ ] 不美化犯罪、暴力、赌博、吸毒
- [ ] 尊重女性、儿童、弱势群体
- [ ] 无涉政、涉军、涉宗教敏感内容
- [ ] 无低俗擦边、性暗示
- [ ] 重生/穿越/异能逻辑自洽，不宣扬宿命论
